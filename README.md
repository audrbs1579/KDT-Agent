
# KDT 교육 PM 자동 에이전트

본 프로젝트는 **설계보고서**를 기준으로 KDT 교육 운영 업무를 지원하는 AI PM 에이전트를 개발하기 위한 자료와 구현 공간입니다.

에이전트는 Azure 환경을 기반으로 교육 과정 일정, 강사·수강생 안내, 자료 수집·정리, 운영 현황 확인 등 반복적인 운영 업무를 자동화하고, 담당자가 확인·승인해야 하는 업무를 구분해 지원하는 것을 목표로 합니다.

## 개발 방향

- `설계보고서/`의 공통 아키텍처와 기능 명세를 개발 기준으로 사용합니다.
- Azure AI Foundry Agent Service, Container Apps, Functions, Service Bus, PostgreSQL, Blob Storage 등을 후보 기반으로 구성합니다.
- Teams, Outlook, SharePoint 등 기존 Microsoft 365 환경과 필요한 범위에서 연결합니다.
- 원본 문서 편집, 퀴즈 검수·게시, 최종 승인 등 사람 작업은 각 기능 명세의 기준을 따릅니다.
- 권한 확인, 민감정보 보호, 실행 이력 관리, 실패 시 사람 확인을 기본 원칙으로 합니다.

## 만족도 조사 운영

한 기수 안에서 며칠에 걸쳐 진행되는 각 강의가 끝날 때마다 객관식 2개·주관식 1개의 Forms 만족도 조사를 1회 운영합니다. 강의 중 매일 보내거나 기수 전체 종료 1회로 제한하지 않습니다. 세부 문항·자동화 범위는 [강의 단위별 만족도](설계보고서/05_강의_단위별_만족도.md#lecture-satisfaction)를 따릅니다.

## 프로젝트 구조

- `docs/`: 에이전트 개발·운영 문서
- `agents/`: 에이전트 애플리케이션 코드 및 도구
- `prompts/`: 시스템 프롬프트와 업무별 프롬프트
- `infra/`: Azure 인프라 구성 코드
- `.github/workflows/`: 배포 자동화 워크플로
- `tests/`: 기능 및 통합 테스트

기존의 `발표 자료/`, `설계보고서/`, `원본 자료/`는 프로젝트의 참고·근거 자료로 유지합니다.


## 문서 형식과 번호 규칙

- `설계보고서/` 안의 MD는 설계·명세·업무 기록용 일반 Markdown으로 작성합니다.
- `설계보고서/` 외에 앞으로 새로 만드는 MD는 `marp: true`가 있는 Marp 발표 자료로 만듭니다. 기존 공통 안내 파일인 이 README는 규칙을 관리하는 문서로 유지합니다.
- 최종 설명용 Marp MD는 `설명 자료/`에 저장합니다. PPT·PPTX 파일은 만들지 않습니다.
- 설계보고서의 정식 문서는 `00_문서명.md` 형식으로 중복 없이 연속 번호를 붙입니다. `00`은 안내·목차입니다.
- **추후 확장은 항상 정식 문서의 마지막 번호**로 둡니다. 새 정식 문서를 추가할 때는 추후 확장 바로 앞에 넣고 추후 확장의 번호를 뒤로 옮깁니다.
- 현재 `12`는 운영 업무 리스트, `13`은 추후 확장입니다. 설명 자료의 대응 문서도 같은 번호·파일명을 사용합니다.
- 번호·파일명을 변경하면 보고서 목차, README, 다른 설계 문서와 설명 자료의 링크·표시 번호도 함께 바꿉니다.
- Excel 같은 보조 자료는 관련 번호 문서에 설명·표를 포함합니다. 원본 파일은 보존하며 보조 파일에 별도 정식 번호를 붙이지 않습니다. 별도 보관한 과거 참고 기록도 보조 자료로 취급합니다.

## 운영 업무 기록

- [12 운영 업무 리스트](설계보고서/12_운영_업무_리스트.md): 에이전트 도입 전에 사람이 하던 교육 운영 업무를 기록하는 통합 표. 고용24 제출 설명도 이 문서에 포함합니다.
- 업무명과 의미는 사람의 작업 관점으로 작성합니다. 에이전트 구축·배포·모델·비용·검증 작업을 운영 업무 목록에 섞지 않습니다.
- 예상 담당자·애매한 조건·자동화 시 주의할 점·의미·예시는 문서 근거가 있을 때만 적습니다. 근거가 없으면 빈칸을 유지합니다. 에이전트 담당을 과거 사람 담당으로 추정하지 않습니다.
- [대응 Marp 설명 자료](설명%20자료/12_운영_업무_리스트.md)는 같은 항목을 업무별 표로 보여줍니다. 업무 내용을 보완할 때 두 문서를 함께 갱신합니다.
- [Excel 샘플 전체 표](설계보고서/09_데이터와_자료_관리.md#legacy-workbook-tables)는 09번 문서에서 확인합니다. 구버전 예시와 현재 운영 기준을 구분합니다.
- [13 추후 확장](설계보고서/13_추후_확장.md)은 전체 정식 문서의 마지막에 둡니다.
