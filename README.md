
# KDT 교육 PM 자동 에이전트

본 프로젝트는 **설계보고서**를 기준으로 KDT 교육 운영 업무를 지원하는 AI PM 에이전트를 개발하기 위한 자료와 구현 공간입니다.

에이전트는 Azure 환경을 기반으로 교육 과정 일정, 강사·수강생 안내, 자료 수집·정리, 운영 현황 확인 등 반복적인 운영 업무를 자동화하고, 담당자가 확인·승인해야 하는 업무를 구분해 지원하는 것을 목표로 합니다.

## 개발 방향

- `설계보고서/`의 공통 아키텍처와 기능 명세를 개발 기준으로 사용합니다.
- Azure AI Foundry Agent Service, Container Apps, Functions, Service Bus, PostgreSQL, Blob Storage 등을 후보 기반으로 구성합니다.
- Teams, Outlook, SharePoint 등 기존 Microsoft 365 환경과 필요한 범위에서 연결합니다.
- 원본 문서 편집, Forms 게시, 최종 승인처럼 사람의 판단이 필요한 작업은 자동화 대상과 분리합니다.
- 권한 확인, 민감정보 보호, 실행 이력 관리, 실패 시 사람 확인을 기본 원칙으로 합니다.

## 만족도 조사 운영

각 기수의 전체 과정 종료 시 1회, 객관식 2개·주관식 1개의 Forms만 운영합니다. 일별·중간·특강·멘토링 만족도는 별도로 운영하지 않습니다. 문항·자동화 범위는 [F06](설계보고서/기능/F06_만족도조사.md)을 따릅니다.

## 프로젝트 구조

- `docs/`: 에이전트 개발·운영 문서
- `agents/`: 에이전트 애플리케이션 코드 및 도구
- `prompts/`: 시스템 프롬프트와 업무별 프롬프트
- `infra/`: Azure 인프라 구성 코드
- `.github/workflows/`: 배포 자동화 워크플로
- `tests/`: 기능 및 통합 테스트

기존의 `발표 자료/`, `설계보고서/`, `원본 자료/`는 프로젝트의 참고·근거 자료로 유지합니다.
