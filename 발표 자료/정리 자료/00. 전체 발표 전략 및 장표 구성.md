# 00. 전체 발표 전략 및 장표 구성

기준일: 2026-10-28 · 결정권자 대상 워크샵 · 본편 28장 · 기준 발표 시간 약 31분

## 1. 발표 목적과 한 문장

> 중요한 결정과 예외 처리를 제외한 반복적인 교육 운영 업무를 최대한 자동 실행하는 Azure 기반 교육 PM 에이전트를 개발한다.

청중이 먼저 이해해야 할 것은 **무엇이 자동으로 처리되고 사람의 손이 얼마나 덜 필요한 운영을 지향하는가**이다. 여러 기수를 운영하는 실제 업무 장면과 결과 화면을 먼저 보여준 뒤 구현 구조·검증·비용을 설명한다. 실제 업무 시간 절감량과 무인 처리율은 향후 측정 항목이며 달성한 수치로 제시하지 않는다.

## 2. 자료 사용 방법

설계보고서는 개발 근거로 유지하고 발표 자료의 순서는 청중의 이해 흐름에 맞춘다. 설계서 번호별 장수 할당은 적용하지 않는다. 한 장에서 여러 설계서를 함께 근거로 사용할 수 있다.

## 5. 화면·그래프와 발표 방식

**시각자료 파일 규칙:** `발표 자료/시각 자료/`에는 SVG로 만든 그래프·도형·그림만 둔다. HTML 파일은 생성하지 않는다. 달력·Forms·대시보드의 화면 구상도 필요할 때 SVG 도형과 텍스트로 표현한다. 사용자 제공 이미지는 참고 자료로 사용할 수 있다.

**제작 시점:** 사용자가 실제 시각자료 제작을 요청했을 때만 SVG 파일을 만든다. 이 문서와 파트별 MD의 시각자료 설명은 제작 명세이며 파일 생성을 지시하거나 허용하는 요청으로 간주하지 않는다. MD 수정·구성 검토만 요청된 경우에는 SVG도 만들지 않는다.

발표자는 장표를 설명 자료로 사용한다. 질문 수·시각물 수를 일률적으로 제한하지 않고 필요한 경우 달력 두 개, 전후 화면, 그래프와 원문 근거를 함께 배치한다.

업무를 설명할 때는 달력·실행 이력·실제 양식 기반 화면을 사용하고, 수치가 있는 구간에만 그래프를 쓴다. 권장 그래프는 과정별 두 객관식 점수와 응답 분포, 검증 후 업무별 사람 개입 기록, 비용 누적 추이다. 실측 전 절감률·성공률·비용 절감 효과를 임의로 만들지 않는다.

같은 합성 기수 A·B, 강사 A·B, 학생 S-01을 연결 사례로 사용한다. 날짜·수치·상태는 장표 사이에서 일치시킨다. 익명 설문을 학생 신원·출결과 연결하지 않고 학생 태도·강사 순위를 만들지 않는다. 출결 사유·의료 원문·계정 ID는 본편에 노출하지 않는다.

가격표·권한 문자열·DB 컬럼 전체·실환경 상세 기록은 07의 부록으로 연결한다. 본편에서는 운영에 미치는 의미를 설명하고 질문에 따라 상세 근거를 연다.
