# 02. 수업 운영부터 과정 종료까지

범위: 본편 04~11장 · 기준 10분 · [전체 구성](<00. 전체 발표 전략 및 장표 구성.md>)

시각자료는 사용자 요청이 있을 때만 SVG 그래프·도형·그림으로 제작한다. 시각 자료 폴더에 HTML을 만들지 않는다. 아래 화면·도식 설명은 제작 명세다.

## 사례와 표현 기준

합성 사례 A·B기수가 같은 날짜에 각자 하루 강의 하나를 운영한다. 만족도는 각 기수의 전체 과정 종료 시 1회만 안내한다. 일일 수업·과정 중간·특강/멘토링 종료에는 발송하지 않는다. 아래 자동 실행 화면은 설계안·화면 구상이며 실제 연동 완료 화면과 구분한다.

## 04장. 한 기수 하루 한 강의, 여러 기수는 동시에 운영된다

- **핵심 문장:** “기수별 달력과 전체 운영 달력을 같은 일정으로 연결합니다.”
- **화면:** 사용자 제공 캘린더 구조를 참고해 기수별 월간 달력과 여러 기수 통합 달력을 나란히 배치한다. 같은 날짜의 A·B기수 강의를 색상과 기수 이름으로 표시한다.
- **설명:** 날짜별 과목·강사가 바뀌고 공동 멘토링에는 담당자가 여러 명일 수 있다. 공동 담당자 수·분할 녹화 수를 강의 개수로 세지 않는다.
- **강조:** 휴강·방학과 수업일을 구분한다. 새로 그린 달력은 예시임을 표시한다.
- **근거:** [F05 일정](../../설계보고서/기능/F05_Outlook_일정.md), [09 일정 양식](../../설계보고서/09_데이터_컬럼_엑셀양식.md).

## 05장. 일정표를 연결하면 월별 수업과 반복 업무를 준비한다

- **핵심 문장:** “일정 변경을 읽어 수업과 연결 업무의 예약을 갱신합니다.”
- **화면:** 일정표 한 행 → 해당 월 Teams 채널 수업 → 실제 회의 링크를 연결한 직원 Outlook → 강사·출결 예약 목록과 별도의 과정 종료 설문 예약.
- **설명:** 일정을 저장하면 허용된 파일을 읽고 기수·수업일·강사를 확인한다. Teams 수업은 1개월 단위로 발행하고 날짜·강사 변경과 휴강에 따라 관련 예약도 갱신한다.
- **강조:** 채널 수업 생성·회의 링크 확인은 실제 UI 절차 검증 대상이다. 달력을 그린 것만으로 연동 성공을 주장하지 않는다.
- **근거:** [F01 규칙](../../설계보고서/기능/F01_과정_기능_규칙.md), [F05 일정](../../설계보고서/기능/F05_Outlook_일정.md), [02 계정 연결](../../설계보고서/02_테넌트_연결.md).

## 06장. 담당 강사에게 준비·자료 확인을 자동으로 연결한다

- **핵심 문장:** “그날 수업을 맡은 강사에게 필요한 준비 업무를 연결합니다.”
- **화면:** 전날 안내 → 교안·출석부·평가 자료의 제출 상태 → 미완료 항목 재확인 화면. 날짜별 강사 교체 전후의 수신자도 비교한다.
- **설명:** 일정과 담당 강사를 매칭해 허용된 채널로 안내하고 저장된 자료·응답으로 상태를 갱신한다. 안내 발송과 실제 준비 완료는 따로 표시한다.
- **강조:** 내부 강사 자료와 학생 배포 자료를 구분한다. 원본 문서 공동 편집은 현재 설계상 사람 작업이다.
- **근거:** [F04 강사 소통](../../설계보고서/기능/F04_Teams_강의_강사소통.md), [KDT 자료 위치](../../설계보고서/KDT_폴더_구조.md).

## 07장. 사전 지각·조퇴·외출 신고를 LMS 확인에 반영한다

- **핵심 문장:** “학생이 미리 남긴 출결 일정까지 읽고 입퇴실을 확인합니다.”
- **화면:** `출결 게시판 신고 → 학생별 예정 시각 → LMS 실제 시각 → 다음 확인·안내`. 10시 지각 입실 예정, 16시 조퇴 예정, 외출 구간을 예시로 비교한다.
- **설명:** 기본 시각의 일반 미클릭 독촉을 일괄 발송하지 않고 신고에 맞춰 확인 예약·문구를 조정한다. 변경·취소도 발송 직전에 다시 확인한다.
- **강조:** 신고 접수는 공식 출결 인정과 다르다. 게시판 조회 실패를 신고 없음으로 처리하지 않는다. 구체적인 시각은 설명용이며 인정 기준은 실제 운영 규칙을 따른다.
- **근거:** [F15 사전 신고·LMS 대조](../../설계보고서/기능/F15_LMS_입퇴실.md), [F14 증빙·공식 판단](../../설계보고서/기능/F14_LMS_서류_반려안내.md).

## 08장. 출결 원천을 대조하고 확인이 필요한 경우를 구분한다

- **핵심 문장:** “자료를 모으고 대조하는 반복 업무를 자동화합니다.”
- **화면:** 호명 출석부·중간출결·Teams 참석 CSV의 3종 종합과 내부 보관 흐름. LMS·게시판 신고는 곁의 대조 근거로 표시한다.
- **설명:** 신고 외출 구간의 미응답, LMS 반영 지연, 원천 상충을 단순 미이행과 구분한다. 원본과 결과를 기수별 내부 위치에 보관한다.
- **강조:** LMS와 게시판을 종합 사이트의 네 번째·다섯 번째 입력 파일로 그리지 않는다. 자료 종합·공식 판정·외부 전달은 서로 다른 완료 상태다.
- **근거:** [F16 중간출결·3종 종합](../../설계보고서/기능/F16_중간출결.md), [F15 LMS](../../설계보고서/기능/F15_LMS_입퇴실.md).

## 09장. 교안·오전 녹화로 퀴즈와 Q&A 정리를 준비한다

- **핵심 문장:** “확인된 수업 자료로 복습과 질문 정리의 초안을 만듭니다.”
- **화면:** 교안·저장 완료된 오전 녹화 → 근거가 있는 퀴즈 초안 → 사람 검수·Forms 게시 → 안내. 옆에 실제 답변·미답변을 구분한 Q&A 예시를 둔다.
- **설명:** 같은 하루 강의의 오전 자료를 오후 퀴즈에 사용한다. 없는 녹화를 분석한 것으로 처리하지 않고 Q&A는 실제 답변과 AI 보조 초안을 구분한다.
- **강조:** 퀴즈의 정답·배점·검수·Forms 게시·응답 다운로드는 현재 설계상 사람 작업이 남는다. 과정 종료 만족도 자동화와 혼동하지 않는다.
- **근거:** [F07 퀴즈](../../설계보고서/기능/F07_퀴즈.md), [F08 Q&A](../../설계보고서/기능/F08_질문답변.md), [F10 녹화](../../설계보고서/기능/F10_영상_수업관찰.md).

## 10장. 과정 종료 시 1회 3항목 설문을 자동 운영한다

- **핵심 문장:** “전체 교육 과정이 끝나면 이 만족도 Forms 한 종류만 1회 운영합니다.”
- **화면:** 과정명·기수·기간/종료일이 표시된 Forms 화면과 `양식 준비 → 과정 종료 확인 → 기본 안내 1회 → 응답 수집` 흐름. 종료한 A기수·운영 중 B기수를 함께 표시한다.
- **문항:** Q1 과정 전체의 교안·자료 준비도와 Q2 설명의 명확성·전달력은 5점 선택형. Q3 좋았던 점·보완점·개선 의견은 주관식이며 기본 선택 항목이다.
- **설명:** 선택형 두 항목을 표 두 행에 넣고 주관식 입력란 하나를 둔다. 종료일·마지막 수업 종료를 확인해 해당 과정에만 기본 안내 1회가 나간다. 미종료 과정에는 발송하지 않는다.
- **강조:** 일별·중간·별도 다문항 최종·특강·멘토링 만족도를 추가하지 않는다. 양식 준비·인증·수집 연결·종료일 변경/중복 방지는 실제 검증 대상이다.
- **근거:** [F06 과정 종료 만족도](../../설계보고서/기능/F06_만족도조사.md), [09 문항·데이터](../../설계보고서/09_데이터_컬럼_엑셀양식.md).

## 11장. 점수 집계와 의견 요약·결과 보관까지 이어진다

- **핵심 문장:** “종료 설문의 응답을 받으면 계산·요약·보관을 연결합니다.”
- **화면:** 해당 과정의 Q1·Q2 평균과 5점 응답 분포, Q3 주관식 주제·원문 근거, 수집/집계/결과 저장 상태.
- **그래프:** 두 항목 평균의 항목별 막대와 응답 분포를 사용한다. 비교가 필요하면 같은 문항·척도의 종료 기수만 비교하고 과정명·종료일·응답 수·대상 인원을 표시한다. 일별 강의 추이를 만들지 않는다.
- **설명:** 수치는 코드/SQL, 주관식 요약은 AI가 담당하고 결과 Excel·요약을 허용된 내부 위치에 저장한다.
- **강조:** 샘플은 예시 데이터다. 주관식 공란은 허용하고 평균에서 제외한다. 과정 전체 응답을 특정 강사의 평가나 학생 신원·출결과 연결하지 않는다.
- **근거:** [F06](../../설계보고서/기능/F06_만족도조사.md), [09 집계](../../설계보고서/09_데이터_컬럼_엑셀양식.md), [F21 화면](../../설계보고서/기능/F21_대시보드.md).
