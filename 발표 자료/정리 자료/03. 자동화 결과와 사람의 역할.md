# 03. 자동화 결과와 사람의 역할

범위: 본편 12~15장 · 기준 4분 · [전체 구성](<00. 전체 발표 전략 및 장표 구성.md>)

시각자료는 사용자 요청이 있을 때만 SVG 그래프·도형·그림으로 제작한다. 시각 자료 폴더에 HTML을 만들지 않는다. 아래 화면·도식 설명은 제작 명세다.

## 이 파트가 남길 메시지

반복 업무의 실행 결과가 모이고, 중요한 판단·예외와 현재 남은 사람 작업이 분명하게 보인다. 대시보드는 자동화의 결과를 확인하고 필요한 조치를 하는 화면으로 설명한다.

## 12장. 여러 기수의 자동화 결과를 한 화면에서 본다

- **핵심 문장:** “기수별로 무엇이 처리됐고 무엇이 기다리는지 확인합니다.”
- **화면:** 기수 A·B의 오늘 수업, 강사 준비, 출결 대조, 과정 종료 설문의 미도래/수집·집계, 실행 장애를 담은 대시보드 구상.
- **설명:** 앞선 하루 사례와 같은 기수·날짜·업무를 사용해 결과를 연결한다. 기수 필터와 전체 운영 보기를 전환한다.
- **강조:** 원천 기준 시각과 수집 상태를 표시한다. 데이터가 없거나 연결이 끊겼을 때 정상·0건으로 보이지 않게 한다. 완성 서비스 화면처럼 소개하지 않는다.
- **근거:** [F21 대시보드](../../설계보고서/기능/F21_대시보드.md), [01 공통 구조](../../설계보고서/01_공통_아키텍처.md).

## 13장. 안내 발송부터 실제 업무 완료까지 상태를 구분한다

- **핵심 문장:** “알림을 보낸 뒤 실제 결과까지 추적합니다.”
- **화면:** 같은 업무의 `예약 → 발송 → 응답/자료 확인 → 검증 → 완료` 이력과 원문·파일 근거. 사람 검수 대기·실패·결과 불명도 함께 표시한다.
- **설명:** 강사에게 안내했다고 교안 제출이 끝난 것은 아니며 Forms 링크를 보냈다고 설문 집계가 완료된 것도 아니다. 업무별 완료 조건으로 상태를 갱신한다.
- **강조:** 단순 발송 건수를 전체 업무 완료율로 제시하지 않는다. 진행률을 사용할 때 대상 업무·완료 정의·분모를 함께 설명한다.
- **근거:** [04 실행 상태·복구](../../설계보고서/04_데이터_권한_복구.md), [F03 체크리스트](../../설계보고서/기능/F03_OT_체크리스트.md), [F21](../../설계보고서/기능/F21_대시보드.md).

## 14장. 운영 사건은 근거와 담당 업무로 연결한다

- **핵심 문장:** “계속 놓치는 업무나 상충 기록은 해결할 일로 묶습니다.”
- **화면:** 교안 준비 지연, 사전 출결 신고와 실제 기록 불일치, 문의 답변 지연의 사건 카드. 근거·담당자·기한·처리 상태를 보여준다.
- **설명:** 같은 사건을 여러 알림으로 쌓지 않고 관련 자료를 모아 담당 업무로 연결한다. 반복 실행 중 오류도 해당 기수·연결의 문제로 분리한다.
- **강조:** 학생의 태도·감정·민원 의도를 판단하는 기능으로 표현하지 않는다. 출결 사전 신고나 익명 설문을 제재 근거로 바꾸지 않는다. 현재 설계의 사건·멘토링 기록을 전용 프로젝트 진행률 관리 기능으로 확대해서 말하지 않는다.
- **근거:** [F09 운영 사건](../../설계보고서/기능/F09_운영경보.md), [F15 사전 신고](../../설계보고서/기능/F15_LMS_입퇴실.md), [F12 멘토링](../../설계보고서/기능/F12_멘토링_사전자료.md).

## 15장. 중요한 결정과 현재 사람 작업을 명확히 남긴다

- **핵심 문장:** “반복 실행은 자동화하고 책임 있는 결정은 사람이 맡습니다.”
- **화면:** 아래 세 범주의 역할 표와 실제 대기 카드. 화면 표시 순서는 자동 실행 → 중요 결정 → 현재 남은 수작업으로 둔다.

| 구분 | 사례 | 설명 |
|---|---|---|
| 자동 실행 개발 대상 | 일정 기반 예약·안내, 과정 종료 만족도 준비·수집·집계, 사전 신고/LMS 대조, 자료 처리·기록 | 승인된 규칙·권한·실제 연결 검증 안에서 반복 실행 |
| 중요한 판단·예외 | 공식 출결 인정·정정, 증빙 최종 판단, 외부 자료 제공, 인증/연결 예외 | 대상·근거·상태를 전달해 담당자가 결정 |
| 현재 설계상 사람 작업 | 원본 문서 공동 편집, 퀴즈 검수·정답/배점·Forms 게시, 다른 Forms 업무의 지정 단계 | 매회 완전 무인화됐다고 표현하지 않고 현 범위와 확대 조건을 설명 |

- **설명:** 개발 목표는 사람의 반복 작업을 최대한 없애는 것이다. 현재 기능별로 남은 작업도 투명하게 보여주고 자동화 확대의 대상으로 관리한다. 이 발표에서 설계보고서의 업무 경계를 임의 변경하지 않는다.
- **근거:** [00 범위](../../설계보고서/00_보고서_안내.md), [F14 증빙](../../설계보고서/기능/F14_LMS_서류_반려안내.md), [F07 퀴즈](../../설계보고서/기능/F07_퀴즈.md), [11 추후 범위](../../설계보고서/11_추후_업데이트.md).
