| 사전 지각·조퇴를 고려하는가? | 게시판 신고·수정/취소를 LMS 실제 시각과 대조해 확인/안내 조정. 공식 인정은 별도 |

| 프로젝트 진행률도 자동 관리하는가? | 현재 사건·멘토링·자료 기록 범위 설명. 전용 단계/완료율 모델은 추가 설계 필요 |

## 5. 요청이 있을 때 제작할 SVG 시각자료와 데이터

사용자가 실제 제작을 요청한 경우에만 SVG 그래프·도형·그림을 만든다. `발표 자료/시각 자료/`에는 SVG 파일만 두며 HTML 파일은 생성하지 않는다. 이 목록은 제작 후보·명세이며 지금 제작하라는 지시가 아니다.

제작 후보는 달력 두 보기, 일정에서 예약으로 이어지는 흐름, 강사 준비 상태, 사전 출결 신고/LMS 대조, 출결 3종 종합, 퀴즈/Q&A, 과정 종료 Forms, 과정별 결과·응답 분포, 대시보드와 실행 이력, 세 계정/Azure 구조, 개발 단계와 비용이다. 화면 구상도 SVG 도형·텍스트로 표현한다.

각 자료는 설계서의 현재 내용과 대조한다. 이전 도식·Excel 샘플에는 변경 전 만족도 주기/문항이 남을 수 있으므로 최신 MD를 기준으로 한다. 본 작업에서는 MD 정리만으로 시각자료를 자동 생성하지 않는다.

합성 사례는 과정 종료 A기수와 운영 중 B기수, 과정을 완료한 비교 기수의 동일 문항 결과로 구성한다. 익명 응답과 학생 신원을 연결하지 않는다. 그래프의 수치·상태·근거는 표와 화면 사이에서 일치시킨다.
