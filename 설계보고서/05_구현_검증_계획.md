## 2. Teams 역할과 구현 순서

### 2.1 `@dataschool` 팀·채널 역할

아래 역할에는 사용자 제공 AI 11기 폴더 구조를 반영했습니다. **수강생 팀 `일반`·기수별 운영 채널·강사팀**은 서로 다른 자료 영역입니다. 이름·날짜·파일명은 참고 예시로 테스트 및 운영을 하면서 바꿀 수도 있습니다. 기수별 운영 채널의 소속 팀과 실제 ID·채널 유형·폴더·권한은 연결 시 확인하며, 기존 공통 팀을 기수마다 중복 생성하지 않습니다.

| 역할·팀 예시 | 채널·대상 | 에이전트 업무 |
|---|---|---|
| `{과정명} {기수} 수강생 팀` | 수강생·강사·운영진. `공지사항`, `01. 출결 게시판`, `02. LMS 정정 요청 게시판`, `03. 교육문의 게시판`, `04. 멘토링 요청 게시판`, `05. 기타 문의 게시판`, `06. 공유 게시판`, `10. 자유 게시판`, `일반` | `일반` 채널 수업 일정·참석 CSV 수집. **파일 공유는 `일반 / 공유 탭`에서만** 수행하며 `01. OT`·`02. 시간표`·`03. 계정`·`04. 타운홀 미팅`·`05. 강의자료`·`06. 프로젝트`·`07. 산출물`·`기타 자료`·`Recordings`를 참고. 다른 게시판은 안내·문의용이며 민감 원본을 첨부하지 않음 |
| `출석 관리 팀` | `{기수} 출석 관리팀` 등. 운영진과 고용24·대학교 등 외부 기관 담당자 | **외부 기관과 출석 업무가 있을 때** 승인된 출석부 공유·소통. 내부 출결 원본·증빙의 기본 보관소가 아님 |
| `강사팀` | `{기수} 강사팀 / 공유 탭` 등. 강사·운영진 | `강사님 양식(산출물, 결과보고서)`·`결과보고서`·`멘토링 일지`·`산출물`·`중간평가문제`·`출석부` 및 강사 매뉴얼. 호명 출석부 원본을 읽고 수강생 배포용 교안·일일 퀴즈 정답과 구분 |
| 기수별 운영 채널 (소속 팀 미확정) | `{기수} 채널 / 공유 탭` 예: `11기 채널`. 별도 `일반` 운영 보고 채널의 실제 소속·수신자는 연결 시 확인 | `교육자료 및 가이드라인`·`운영관리 매뉴얼`·`상담일지`·`중간평가 및 설문`·`출석부`·`커리어멘토링`·`타운홀미팅`·`프로젝트` 및 루트 명단·시간표. **`출석부 / 월 / 주차 / 일자`에 내부 3종 원본·종합본을 별도 파일로 보관**. 상담·계정·평가 결과 등은 실제 열람 권한 확인 |

현재 공통 팀에서 다른 기수 자료가 보일 수 있습니다. 문서에서 기존 자료가 기수별로 완전히 차단되어 있다고 가정하지 않습니다. 표준 채널은 팀 멤버십을 따르고 비공개·공유 채널은 별도 조건을 확인합니다. 에이전트는 넓은 열람 권한이 있어도 **해당 업무에 지정된 과정·파일만** 처리하며 기존 권한을 임의 회수하지 않습니다.

**보관과 외부 공유를 구분하는 업무 지시**

- 내부 보관: `대상 기수·수업일·파일 종류·버전 → 확인된 내부 출석부 폴더에 저장 → 결과 링크 보고`.
- 외부 업무: `기관·업무 목적·수신 채널/담당자·공유할 출석부 버전 지정 → 매니저 검수·승인 → 출석 관리 팀에 전달 → 전달 결과 기록`.
- 구조·위치가 미확정이거나 기관·자료·승인이 빠지면 확인 대기로 두고 임의 저장·외부 전송하지 않습니다. 병가 원본·판독 결과를 출석부와 함께 자동 외부 공유하지 않습니다.
- 운영 채널 시간표와 수강생 `일반 / 02. 시간표`의 기준 원본·배포본 관계를 지정합니다. Forms 결과는 사람이 내려받아 운영 채널 `중간평가 및 설문`에 저장할 예정이며, 현재 자동 수집 중이라는 뜻이 아닙니다. 제한된 개인 자료·일일 퀴즈 검수본·정답의 위치는 별도로 지정합니다.

### 2.2 구현 순서

1. **권한·대상 확인:** 세 계정 관리자 권한은 06의 확인 사실을 사용합니다. 라이선스·정책과 실제 팀·채널·SharePoint 구조·공통 팀 가입의 영향을 별도로 확인합니다.
2. **연결 구축:** 저장된 파일 다운로드·파싱, Teams 채널 수업 일정의 컴퓨터 사용, 실제 회의 링크의 직원 Outlook 반영, 봇 안내·응답 수신, LMS·중간출결·출결 종합 사이트를 연결합니다.
3. **공통 플랫폼:** 기능 ON/OFF, 규칙 버전·예약·대기열·DB·권한·감사·사람 작업 대기 상태를 구현합니다. 확인된 역할·ID 매핑을 재사용합니다.
4. **주요 운영:** 사람이 편집한 OT·일정·면접·출석부 파일을 읽고, Forms 응답 화면에서 Excel 다운로드/내보내기로 받은 파일을 집계합니다. Forms 생성·가져오기 검토·정답/배점 설정·게시·링크 등록·응답 Excel 다운로드는 사람의 담당 업무로 둡니다. 새 응답은 다시 다운로드한 파일로 반영합니다.
5. **연결 기능:** 오전 첫 저장 완료 녹화로 오후 퀴즈 초안을 준비하고 검수·게시 후 안내합니다. LMS 증빙 1차 판독·매니저 최종 판단, 입퇴실 누락 안내, 3종 출결 종합·내부 보관, 승인된 외부 출석 업무, 운영 경보·영상 관찰을 연결합니다.
6. **운영 적용·개선:** 실제 연결·권한·대상·완료 조건을 확인한 기능을 운영에 적용합니다. 모델 품질·속도·가성비는 테스트·운영 중 측정하며 교체합니다. 사전에 최적 모델이나 고정된 품질을 확정해야 한다는 뜻은 아닙니다. 새 기수는 규칙·양식만 복제하고 실제 계정·채널·폴더를 다시 확인하며 미완성 연결을 작동 중으로 표시하지 않습니다.

## 3. 공통 운영 품질 기준

수치는 제안 목표이며 현재 달성한 성능이 아닙니다. 배포 전 확인과 운영 중 로그·대시보드로 점검하고, 기준 이탈은 해당 기능 중단·담당자 경보로 처리합니다.

| 항목 | 확인 상황 | 기준 |
|---|---|---|
| 노트북 독립 | 운영자 PC 종료 | 서버 자동 실행, 사람 단계는 대기 표시 |
| 권한·대상 | 다른 기수 자료가 보이는 계정·잘못된 폴더 | 업무 범위 밖 수집·전달 0건, 미확정 경로 쓰기 차단 |
| 원본 문서 | 사람의 동시 편집·버전 변경 | 원본 덮어쓰기 없음, 저장된 버전 대조·재수집 |
| 일정 | 월별 발행·재시도·휴강·강사 교체 | 지정 1개월만 생성, 동일 채널 수업 중복 생성 방지 |
| 퀴즈 | 오전 파일 지연·분할 녹화·미검수·미게시 | 없는 구간을 근거로 쓰지 않음, 게시 링크 확인 전 발송 차단 |
| 과정 유연성 | 단기·출결 없음·수기 입력 | 등록된 기능은 설정 조합, 수기 확인·입력은 사람 |
| 취소·중복 | 변경·전송 직후 응답 유실 | 취소 발송 0건, 결과 불명은 확인 대기 |
| LMS·증빙 | 빈 오류 화면·다른 날짜·저화질 | 오류를 미이행으로 판정하지 않음, 승인·반려는 매니저 |
| 출결 보관·외부 공유 | 내부 종합본·기관별 출석 업무 | 내부 출석부 폴더 보관과 승인된 외부 전달을 별도 완료 상태로 관리 |
| 영상 | 화면 공유·저화질·관찰 불가 | 안 보이는 학생을 불성실로 판정하지 않음 |
| 컴퓨터 사용 | 화면 변경·MFA·세션 만료 | 완료 검사, 정책 차단 시 사람 확인, 권한 우회 없음 |
| 비용 | 조회 지연·추정·공통 비용 배분 | 중복 합산 없음, 원천·사용 기간·추정 여부 표시 |
| 복구 | DB 복원·실행기 재시작 | 과거 외부 작업 무단 재실행 방지 |

규모·예약 허용 오차·장애 탐지 시간·RTO·RPO는 운영 요구에 맞춰 확정합니다. 확인 없이 확정 성능을 주장하지 않습니다.

과정 수·수업시간·자료량·조회 주기·동시 작업·보관 기간·라이선스·할인·크레딧에 따라 달라집니다. 08 모델 비교는 후보 단가, 10 비용 관리는 조회 비용·미반영 추정·배분·알림과 변경 가능한 계산 예시를 다룹니다. 금액은 참고용이며 확정 견적·예산 승인 요청이나 비용 달성 실적이 아닙니다.

## 5. 비용 통제

- 통계는 SQL로 계산하고 같은 버전·권한의 문서·영상 구간은 중복 분석하지 않습니다.
- 작업별 토큰·단계·시간·비용·허용 도메인 한도를 둡니다.
- Azure Budget은 자동 중단 장치가 아니므로 자체 사용량 한도를 병행합니다.
