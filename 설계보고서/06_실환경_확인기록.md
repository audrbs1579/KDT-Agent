## 1. 확인 방식

사용자가 직접 로그인한 Azure/Entra 화면과 CLI 조회 결과를 확인했습니다. 기본 조사는 읽기 전용이며 자격 증명·토큰 추출, 운영 리소스 생성, 모델 배포, 앱 권한 변경은 하지 않았습니다. 다만 명명 규칙 확인용 임시 Foundry 리소스를 생성·삭제한 이력은 5절에 별도로 기록합니다. 이를 운영 배포 완료로 보지 않습니다.

## 3. 여기서 도출한 개발 기준

1. 다른 구독을 새 기준으로 삼지 않고 **엘릭서 구독** 안에서 개발합니다.
2. AI PM용 개발/운영 리소스 그룹은 별도로 만들 것을 제안합니다. 현재 생성하지 않았습니다.
3. 기존 리소스는 변경하지 않습니다. 새 자동화 계정에는 신규 시스템과 연결 대상에 필요한 권한만 부여합니다.
4. 배포 위치·모델 선택은 세 계정의 연결 조건을 확인한 뒤 별도 검토합니다.
5. 관리자 계정의 권한을 에이전트에 그대로 복사하지 않습니다. 자동화 앱에는 실제 업무 도구별 권한을 부여합니다.
6. 조직 전체 관리 권한이 확인되어도 조직 정책·계약·서비스 라이선스의 적용을 무시하지 않습니다.

### 당시 참고 결정과 현재 적용 원칙

- 2026-10-19에는 Korea Central 중심·computer use 지원 리전 예외안을 검토했습니다. 이는 과거 검토 이력이며 현재 모든 리소스를 같은 지역에 고정하는 결정이 아닙니다.
- 배포 옵션은 Global Standard·Flex·Batch 등을 가격·기능 기준으로 비교하는 참고안입니다. 실제 호출·모델 품질·처리 위치는 테스트·운영에서 확인·변경합니다.
- 지역별 카탈로그·쿼터와 정책 할당 목록 조회는 완료된 조사입니다. 신규 운영 앱·모델 배포·관리자 동의·실제 업무 연결 성공까지 확인했다는 뜻은 아닙니다.

## 6. 확인 기록과 미확인 목록의 관리

06은 확인한 값·근거·실패 결과를 보존하고, 07은 아직 확인하거나 결정할 항목을 관리합니다. 확인이 끝난 체크 항목은 근거·확인일을 06에 기록한 뒤 07에서 삭제합니다. 관리자 요청을 보냈다는 것만으로 완료 처리하지 않습니다.

권한이 없어 확인하지 못한 항목은 완료로 처리하지 않고 관리자 확인 대상으로 남깁니다. 설정 조회와 실제 API 호출 확인도 구분합니다. 이번 수정은 기존 증거와 문서를 대조한 결과이며, 미확인 정책을 새로 검증했다는 뜻은 아닙니다.

## 7. 여러 계정의 브라우저 사용

Azure 탭 3개와 Microsoft 365 탭 3개를 여는 것만으로 로그인 세션이 독립되지는 않습니다. 같은 브라우저 프로필의 쿠키를 공유하면 계정 전환이 다른 탭에 영향을 줄 수 있습니다.

확실한 계정 분리는 브라우저의 서로 다른 프로필/격리된 세션으로 처리하거나, 계정 하나씩 확인하고 매번 조직 이름을 검증하는 방식으로 합니다. 포털의 실제 URL·계정·조직이 확인되지 않은 탭은 해당 조직의 증거로 사용하지 않습니다.

## 11. 기수별 일별 강의 운영 기준 보완 — 2026-10-28

출결 게시판·LMS 정정 요청 작성 방식은 이후 사용자 제공 사진으로 보완했습니다. 확인 범위는 학생 글의 제목·본문 항목·사례·편집 표시이며, 실제 관리자 답변·승인·LMS 수정 완료·연동 권한은 확인한 것이 아닙니다. 익명화한 필드와 처리 기준은 F15 및 09의 13.1절에 기록합니다.

**일정 운영 기준(사용자 설명·캘린더 기준): 한 기수는 수업일마다 하루 강의 일정 1개를 운영하고, 같은 날짜에 여러 기수가 각각의 강의를 동시에 운영합니다.** 기수별 달력에는 해당 기수의 일별 강의 하나가 보이며, 전체 달력의 같은 날짜에 보이는 여러 강의는 서로 다른 기수의 일정입니다. 강사·과목은 날짜에 따라 바뀔 수 있고, 공동 멘토링의 복수 담당자도 하루 일정 하나에 연결합니다. 오전·오후 출결이나 분할 녹화는 같은 하루 강의의 내부 구간입니다.

근거는 사용자가 제공한 기수별 월간 캘린더·여러 기수 통합 캘린더 이미지와 운영 설명입니다. 월간 화면의 강사·과목 변경과 공동 멘토링 표기는 날짜별 하루 일정의 속성으로 반영합니다. 실제 캘린더 ID·기수별 색상 매핑·권한·연동 성공을 새로 확인한 기록은 아닙니다.
