# 08. 모델 가격 비교 (운영 모델 선정 근거)

[문서 목록](00_보고서_안내.md)

기준일: 2026-10-20 (Azure Retail Prices API·OpenAI 공식 가격표 재검증 완료)

**가격·후보 비교용 참고 자료이며 모델 선정 승인서가 아닙니다.** 현재 후보를 실제 운영에 적용하고 테스트·운영 중 한국어 품질·담당자 수정률·도구 호환성·응답 시간·실제 비용을 보며 더 좋은 모델 또는 더 가성비 있는 모델로 변경합니다. 후보·순위·리전은 확정값이 아닙니다. 실제 연결·권한·발송 대상·필요한 사람 승인은 별도로 확인하며 이 원칙을 모델 교체로 완화하지 않습니다.

## 0. 전제 조건

| 항목 | 내용 |
|---|---|
| 리소스 지역 | 아래 가격·카탈로그는 당시 `Korea Central` 등 조사 지역 기준. 실제 생성·저장·처리 지역은 상황에 맞게 테스트·운영에서 선택·변경 |
| 배포 옵션 | `Global Standard`를 포함해 모든 배포 옵션을 가격·성능 기준으로 비교 |
| 가격 출처 | Azure Retail Prices API (`prices.azure.com`), `armRegionName eq 'koreacentral'`, USD 목록가와 `currencyCode=KRW` 목록가 |
| 가격 기준 | 1백만 토큰(1M) 단위 |
| 제외 사항 | VAT, 계약 할인, 약정(Provisioned) 요금, 실제 청구 환율 |

> 주의: 위 가격은 공개 목록가이다. 실제 청구액은 계약 조건과 환율에 따라 달라진다.

## 2. 비 OpenAI 모델 단위 및 배포 가능 여부

### 2.2 배포 가능 여부 (Korea Central 카탈로그 조회 결과)

- 조회 명령: `az cognitiveservices model list --location koreacentral`
- 카탈로그에 있는 비 OpenAI 제공사: Alibaba, Mistral AI, Cohere, DeepSeek, Meta, Black Forest Labs, OpenAI-OSS, xAI(Grok), Moonshot(Kimi), MAI, Microsoft(Phi) 등
- 배포 SKU는 `GlobalStandard` 또는 `DeveloperTier`만 확인됨. 지역 내 `Standard` SKU는 확인되지 않음
- 할당량(quota) 항목 중 `AIServices.GlobalStandard.*` 형태로 66개가 조회됨. 모든 현재 사용량은 0이다
- 실제 배포 성공 여부는 확인하지 않았다 (배포는 승인 없이 하지 않음)

## 3. 작업 성격별 모델 선택 가이드 (초안)

**과정 종료 만족도(F06, 2026-10-28 보완):** 과정 종료 시 1회 객관식 2개·주관식 1개 중 점수 매핑·평균·분포·응답 건수는 코드/SQL로 계산합니다. AI는 허용된 주관식 요약·주제 분류에 사용하며 원문 근거를 남깁니다. 승인 템플릿의 제목·날짜·강사 치환은 일반 코드로 처리하고 매 강의마다 문항을 새로 창작하지 않습니다. 브라우저 실행/Logic Apps 비용은 모델 토큰 비용과 별도로 관리합니다.

| 작업 유형 | 후보 | 근거 |
|---|---|---|
| 분류, 요약, 태그 | gpt-6-luna, DeepSeek V4 Flash, Grok 4.1 | 입력 단가 0.2 USD/1M 이하 |
| 일반 업무 판단 | gpt-6.1-sol, gpt-6-sol, gpt-5.6-terra | 입력 2 USD/1M, 출력 10~12 USD/1M |
| 복잡한 판단·위험 신호 해석 | gpt-6-astra, gpt-5.6-sol | 입력 4~10 USD/1M 이상 |
| 화면 기반 컴퓨터 제어 | computer-use-preview 등 지원 모델 | 당시 제공 이력은 06 참고. 지원 모델·리전은 테스트·운영에서 재선택 |

- 이 표는 가격 기준 참고안이다. 실제 운영에 적용하고 테스트·운영 중 지표(품질·담당자 수정률·오탐·재요청·지연·비용)를 보며 더 좋은 모델 또는 더 가성비 있는 모델로 바꾼다. 비싼 모델로만 올리는 정책이 아니며 사전에 최적 모델을 확정했다고 주장하지 않는다.

## 5. 토큰 구간 기준 (ShortCo/LongCo)

- 공식 가격 페이지는 GPT-6.x, GPT-5.6 항목을 "short context / long context"로 표기한다.
- GPT-5.4 항목에는 "<272k / >272k context length" 기준이 명시되어 있다.
- GPT-6.x, GPT-5.6 항목의 기준 토큰 수는 조회한 페이지 본문에서 확인되지 않았다. 가격 칸이 `$-`로 렌더링되어 값도 페이지에서 직접 읽지 못했다.
- 2차 확인: OpenAI 공식 가격 페이지(developers.openai.com/api/docs/pricing)에는 gpt-6-luna, gpt-6-sol, gpt-6.1-sol, gpt-6-astra, gpt-5.6-* 에 대해 Long context 열(입력, 캐시, 출력)이 표로 있다. 예: gpt-6-luna 긴 문맥 입력 $0.20 / 출력 $0.75 (짧은 문맥 $0.10 / $0.50). 다만 6.x 항목에는 "<272K" 같은 기준 토큰 수가 표 안에 적혀 있지 않다. 긴 문맥 기준 토큰 수는 여전히 미확인이다.
- 이 표는 OpenAI 직접 API 가격이지만, Azure Retail Prices API(`armRegionName eq 'koreacentral'`)와 대조한 결과 **GPT-6.x 및 GPT-5.6의 ShortCo·LongCo(Standard·Flex·Cached Input·Cache Write) 단가가 OpenAI 공식 표와 100% 일치함**을 확인했다.
- 결론: 구간 경계 토큰 수 자체는 공식 표에 숫자(`<272K` 등)가 적혀 있지 않으나, 긴 문맥(`LongCo`) 요금 자체는 Azure Retail API에 모두 등록되어 있다. 비용 계산 시 긴 문맥 요금을 상한으로 잡는다.

## 6. 제시 후보의 단가와 선정 기준

| 순위 | 옵션 | 입력 / 출력 (KRW per 1M, 짧은 문맥) | 배포 가능 여부 |
|---|---|---|---|
| 1 | gpt-6-luna Global Flex (요청 단위 `service_tier: flex`) | 68.24 / 341.19 | 공식 문서상 지원 목록에 gpt-6-luna 포함. 별도 SKU가 아니므로 카탈로그 부재는 문제가 아님. 실제 호출 검증 전까지 미확인. 프리뷰, SLA 없음, 429 가능 |
| 2 | gpt-5-nano Global Standard | 68.24 / 545.90 | 구독 내 기존 사용 이력·한도 확인. 신규 에이전트의 도구·품질 요구 충족은 별도 확인 |
| 3 | gpt-6-luna Global Standard | 136.48 / 682.38 | 당시 카탈로그 확인 (`GlobalStandard`). 실제 호출·품질은 테스트·운영에서 확인·개선 |
| 4 | gpt-5.6-luna Global Standard | 272.95 / 1,637.70 | 카탈로그 확인. 실제 업무 호출·품질은 별도 확인 |
| 5 | gpt-6-sol Global Standard | 2,729.50 / 13,647.50 | 카탈로그 확인. 실제 업무 호출·품질은 별도 확인 |

- **위 순위는 이 표에 포함된 후보의 입력·출력 단가 비교**이며 사용 가능성·품질 순위가 아니다. Standard 후보 중 표의 단가가 가장 낮은 것은 **gpt-5-nano**다. `gpt-6-luna Global Standard`는 저비용 대안이지만 최저가는 아니다.
- 모델은 기능별 참고 후보를 운영에 적용하고 테스트·운영 중 한국어 품질·문맥 길이·도구 호출·응답 기한·비용을 보고 교체한다. 더 비싸거나 더 저렴한 모델로 변경할 때도 충족할 기능·품질·비용과 적용 버전을 기록한다.
- 위 표의 luna Flex 단가는 luna Standard보다 낮지만, 다른 모델·Batch·캐시·문맥 구간까지 포함한 절대 최저가를 뜻하지 않는다. 공식 문서에 따르면 Flex는 별도 배포 SKU가 아니라 Global Standard 배포에서 요청마다 지정하는 옵션이다. 프리뷰이며 SLA가 없고 429가 날 수 있으며, 지원 안 되는 모델이면 자동 대체 없이 HTTP 400이 난다. 실제 호출로 검증해야 한다.
- 판단 작업의 예시 후보로 gpt-6-sol 등이 있으나 가격 차이가 품질 향상을 보장하지 않는다. 테스트·운영 결과에 따라 더 좋은 모델 또는 더 가성비 있는 모델로 기능별 변경한다.
- Data Zone은 필수가 아니며, gpt-6-astra 기준 Global보다 약 20% 높다(입력 16,377 vs 13,647.50).
- Batch(50% 할인): 공식 배포 유형 문서에 따르면 Global Batch는 모든 Azure 리전에서 24시간 비동기 작업용으로 50% 할인된다. Retail API(`currencyCode=KRW`, Korea Central)에서도 `gpt-5.5`·`gpt-5.4`·`gpt-5`·`gpt-4.1` 등의 Batch KRW 항목(예: `5.5 ShortCo Batch inp Gl` 3,411.88원 / 출력 20,471.25원, `GPT 5 Nano Batch Inpt Glbl` 34.12원 / 출력 272.95원)이 직접 확인되며, GPT-6.x 계열은 동일 50% 할인율의 `Flex` 미터가 등록되어 있다. 실시간 응답이 필요 없는 작업에만 쓸 수 있다.
- 비 OpenAI 비교 예시: DeepSeek V4 Flash는 입력 0.19 / 출력 0.51 USD per 1M(약 259 / 696 KRW)이다. 입력은 gpt-6-luna Standard보다 비싸다. 한국어 품질과 배포 가능 여부는 별도 확인이 필요하며, 이 표가 모든 제공사의 모든 모델 중 절대 최저가를 인증하는 것은 아니다.

## 7. 남은 확인 사항

1. 계약 할인·약정(Provisioned) 요금: 이 세션에서는 계정 청구 정보가 없어 확인 불가
2. 실제 청구 환율, VAT 반영 여부
3. GPT-6.x, GPT-5.6 토큰 구간 기준 값
4. Flex 실제 호출 가능 여부(요청 단위 옵션, 배포 시 검증), Batch 실제 사용 가능 여부
5. 화면 제어 등 기능별 모델·리전·배포 유형을 실제 테스트·운영에서 선택·변경하고 쿼터·처리 위치·정책을 확인. 당시 카탈로그 이력은 06 참고
6. gpt-5-nano·gpt-6-luna 등 후보의 한국어 품질·도구 지원을 실제 업무로 확인하고 운영 지표로 점검

# 10. AI PM 에이전트 전용 ACR·비용 관리 대시보드

[문서 목록](00_보고서_안내.md)

기준일: 2026-10-21

**예산 승인을 위한 견적서가 아닌 비용 관리·계산 방식의 참고 자료입니다.** 아래 시나리오 금액·규모·모델·기간은 설명용 예시이며 실제 테스트·운영량·가격·리전·구성에 따라 바뀝니다. 예시가 실제 비용 달성 실적이나 리소스 용량 검증을 뜻하지 않습니다.

## 1. 관리 대상과 비용 표현

- **대상:** `@msacademy` 엘릭서 구독의 AI PM 전용 운영 리소스와 상황별로 선택한 리전의 모델입니다. 다른 회사 리소스를 자동 포함하지 않습니다.
- **목표 ACR:** 원문의 약 `2,000` 단위는 목표·배정 한도 설정의 출발점입니다. 통화·적용 기간·계약/크레딧은 실제 확인 후 입력하며 확정 월 운영비로 해석하지 않습니다.
- **Azure 조회 비용(`ActualCost`):** Cost Management에서 조회한 사용 비용입니다. **청구서 발행 전에는 추정 비용이며 지연·추가 사용·조정으로 달라질 수 있습니다.**
- **미반영 사용 추정:** 앱의 모델별 토큰·호출 로그와 적용 단가로 계산한 자체 추정입니다. 실제 계약·캐시·요금 구간·실패 호출·통화에 따라 청구와 차이가 날 수 있습니다.
- **수동 보정:** 별도 근거·기간·통화·담당자·보정 ID를 가진 조정입니다. 자동 수집분과 중복되지 않는지 확인하며 원본 조회 비용은 덮어쓰지 않습니다.

여기서 ACR은 프로젝트의 **Azure Consumed Revenue 관리 지표**를 뜻하며 R03 Azure Container Registry와 구분합니다. Cost Management 조회 금액이 별도 계약의 ACR 인정 실적이나 남은 크레딧과 같다고 단정하지 않습니다.

## 2. 수집·대조·배분

1. **6시간 주기 조회:** 전용 리소스 범위의 Cost Management 데이터를 수집합니다. 이는 조회 간격이지 비용 반영 지연의 상한이 아닙니다. 계약·서비스별 지연이 달라 EA/MCA는 통상 8~24시간, 종량제는 최대 72시간이 걸릴 수 있습니다.
2. **스냅샷 갱신:** 같은 리소스·미터·사용 기간·통화의 누적 조회 결과는 최신 버전으로 갱신합니다. 6시간마다 받은 누적 금액을 계속 더하지 않습니다. 수집 시각과 비용 사용 기간을 별도로 기록합니다.
3. **사용 로그 대조:** 리소스·미터·사용 기간 등으로 이미 조회 비용에 반영된 로그를 구분합니다. **대조로 미반영이 확인된 부분만** 조회 비용에 더해 ‘합산 추정’으로 표시할 수 있습니다.
4. **대조 불가:** 반영 범위를 확인할 수 없으면 두 금액을 나란히 보여주고 합계는 만들지 않습니다. ‘조회 비용 + 당일 토큰 전체’를 그대로 더하지 않습니다.
5. **모듈·기수별 배분:** Azure가 기능·기수별 청구를 직접 제공한다고 가정하지 않습니다. 모델/실행 로그와 배분 규칙으로 나눈 값은 **배분 추정**으로 표시하고 공통·미배분 비용을 남깁니다. 같은 리소스를 여러 기능 행에 중복 합산하지 않습니다.
6. **통화·수동 보정:** 같은 기간·통화로 대조하고 환산 기준을 표시합니다. 수동 보정의 중복 ID를 막고 자동 데이터 반영 후 보정 유지·해제 이력을 관리합니다.

## 4. 알림·자동 비용 제어

- `비용 사용 비율 = 선택한 비용 기준 ÷ 같은 기간·통화의 목표액`. UI에서 ‘달성률’이라고 부르더라도 소비를 늘려야 하는 목표로 해석하지 않습니다.
- 대조 불가 추정은 조회 비용에 더해 임계값을 계산하지 않습니다. 대신 앱 자체 호출량·토큰 상한을 별도로 감시합니다.
- 기간·대상·임계값·비용 기준별 첫 초과 알림을 기록해 중복을 막습니다. 조정으로 비율이 내려가도 기존 발송 이력은 보존합니다.
- `50/70/80%`는 담당자 알림, `90%`는 추가 크레딧 검토·선택 재분석 승인 전환, `100%`는 선택 고비용 작업 제한으로 설정할 수 있습니다.
- 필수 일정·출결·공지 업무를 임의 중단하지 않습니다. 모델 전환은 해당 기능의 품질·도구 지원이 확인된 정책 안에서만 수행합니다.
- Azure Budget 자체가 소비를 중단하지는 않습니다. 기존 회사 리소스의 삭제·축소·정지는 별도 권한·승인입니다.

`cost_snapshots`, `usage_events`, `cost_allocations`, `agent_acr_targets`, 알림 이력에 원천·사용 기간·통화·수집 시각·대조 상태·보정 근거를 저장합니다.

동일 범위·기간의 포털과 대조하고, 누적 스냅샷 중복·당일 토큰 중복·수동 보정 중복·공통 비용 배분 합계를 검사합니다. 갱신 지연이나 조회 실패를 비용 0으로 표시하지 않습니다.

운영비는 기수 수·모델·호출량·캐시·문서/영상 분량·실행기 시간·보관·라이선스·계약에 따라 변합니다. 고정 월 금액을 약속하지 않으며 VAT·할인·환율·크레딧은 별도 확인합니다.

## 6. 규모별 월비용 계산 예시 — 참고용·변경 가능

다음은 **AI PM Azure 기본 구성 일부의 소계**를 설명하기 위한 예시입니다. 총 운영비 견적이나 예산 요청이 아닙니다. DB 예시 단가는 03의 기존 조사값, 모델 예시 단가는 08의 기존 조사값을 사용했으며 이번 수정에서 새 가격을 조회한 것은 아닙니다.

- DB 계산 예시: `$0.246/시간 × 730시간 = $179.58`, 저장소 `32GB × $0.131/GB·월 = $4.192`. 합계 `$183.772/월`.
- 모델 계산 예시: 기수당 수업일 20일, 하루 입력 100,000·출력 20,000토큰, 입력 `$0.10/1M`·출력 `$0.50/1M`이면 `20 × (0.1 × 0.10 + 0.02 × 0.50) = $0.40/기수·월`. 이는 gpt-6-luna 짧은 문맥 Standard의 당시 단가를 넣은 산술 예시일 뿐 모델 추천·호출량 실측이 아닙니다.
- 아래 기타 인프라·분석 예산은 **계산 구조를 보여 주려고 임의로 둔 값**입니다. 앱·예약·대기열·로그·파일·추출·영상의 실제 미터 견적을 조회했다는 뜻이 아닙니다.

| 시나리오 예시 | 기수·학생 수 가정 | DB·저장소 USD | 모델 USD | 기타 인프라 가정 USD | 문서·영상 분석 가정 USD | 예시 소계 USD/월 |
|---|---|---:|---:|---:|---:|---:|
| 소규모 | 1기수·30명 | 183.772 | 0.40 | 40 | 20 | 244.17 |
| 기준 비교 | 3기수·90명 | 183.772 | 1.20 | 80 | 60 | 324.97 |
| 확장 비교 | 6기수·180명 | 183.772 | 2.40 | 160 | 120 | 466.17 |

모든 행에 같은 DB를 둔 것은 산술 비교를 위한 가정이며 6기수 처리 성능을 검증한 것이 아닙니다. 부하에 따라 DB·실행기·SKU를 바꾸면 소계도 다시 계산합니다. 소계는 마지막에 소수 둘째 자리로 반올림합니다.

**제외 항목:** 개발 환경 별도 비용, 고가용성·추가 백업, 선택 Windows VM/PAD·추가 M365 라이선스, 별도 전송 비용, 개발·유지보수 인건비, VAT·계약 할인·환율·크레딧. 필요한 항목을 더한 뒤에만 전체 운영비로 비교합니다. 원문의 `2,000`과 통화·기간이 확인되기 전에는 이 표를 직접 비교하지 않습니다.

운영 중 모델·리전·분석량을 바꿀 때는 사용량·단가·예외 비용을 갱신합니다. 이 예시를 더 정확한 예측치로 계속 보완할 수 있으나, 현재 워크샵에서 예산 승인이나 확정 금액을 요구하는 것은 아닙니다.

# F18. Azure 조회 비용·사용 추정·예산

[전체 목록](../00_보고서_안내.md)

난이도: 3

비용표·규모·모델·리전은 워크샵 참고안이며 예산 승인 요청이나 확정 견적이 아닙니다. 실제 테스트·운영에서 사용량과 가격을 갱신하며 모델·리전 변경도 반영합니다.

## 목적

`@msacademy` 엘릭서 구독의 **AI PM 전용 리소스**에 대해 Azure 조회 비용·AI 사용 추정·모듈/기수별 배분 추정을 관리합니다. `ActualCost`도 청구서 발행 전에는 추정 비용이며 최종 금액을 보장하지 않습니다.

## 입력·설정

대상 구독·전용 리소스 범위·상황별 선택 리전의 모델, 목표 ACR·통화·적용 기간, 6시간 조회 주기, 원천별 사용 기간·수집 시각·단가/배분 규칙, `50/70/80/90/100%` 알림·수신자, 선택 고비용 작업 제한.

원문의 약 `2,000` 단위는 목표 설정의 출발점입니다. 실제 통화·기간·배정 한도·크레딧/계약은 확인 후 등록합니다. 기존 회사 전체 비용이나 별도 계약의 ACR 인정 실적과 자동 동일시하지 않습니다.

**폴더 구조와의 관계:** 운영 채널의 `운영관리 매뉴얼 / Azure 관리 매뉴얼.docx`와 수강생 `일반 / 06. 프로젝트 / 프로젝트 가이드 / 0. 운영 가이드 / Azure 비용 관리 요령.pptx`는 안내 자료입니다. 운영 비용 원천은 Azure 조회·사용 로그이며 학생 프로젝트 비용과 AI PM 운영 비용을 섞지 않습니다. 여러 영역의 계정 Excel을 인증정보 수집·모델 입력 원천으로 사용하지 않습니다. 이름·파일 구성은 참고 예시로 테스트 및 운영을 하면서 바꿀 수도 있습니다.

## 처리 구조

`6시간마다 Azure 비용 조회 → 같은 범위·사용 기간의 최신 스냅샷 갱신 → 앱 토큰/호출 로그와 반영 범위 대조 → 미반영이 확인된 부분만 합산 추정 또는 대조 불가 시 별도 표시 → 모듈·기수별 배분 추정 → 대시보드·임계값 알림·허용된 선택 작업 절감`

누적 스냅샷을 계속 더하거나 조회 비용에 당일 토큰 전체를 더하지 않습니다. 중복 제외 근거가 없으면 **조회 비용과 사용 추정을 나란히 표시**합니다. 통화·기간이 다른 금액도 그대로 합산하지 않습니다.

## 리소스·권한

Azure Cost Management, PostgreSQL, Azure Monitor, Durable Functions, Teams. 조회 역할만 부여하며 기존 리소스 삭제·축소·중단은 별도 권한·승인입니다.

## 저장·출력

`cost_snapshots`, `usage_events`, `agent_acr_targets`, `budget_policies`, `cost_allocations`, 알림 이력.

상단 3개 카드(목표/조회 비용·운영/수집 상태·알림), 차트 3종(누적 추이·모델/리소스 구성·기수/기능 배분), 상세 표·Excel 붙여넣기를 제공합니다. 원천·사용 기간·추정/배분·대조 상태·수집 지연·수동 보정 근거를 표시합니다([10 비용 관리](../10_비용_산출_시뮬레이션.md)).

## 예외·승인

- 6시간은 조회 주기이며 비용 반영 완료 기한이 아님. 조회 실패를 비용 0으로 표시하지 않음.
- 대조 불가 추정을 합산해 예산 경보를 만들지 않고 별도 호출량·토큰 상한 병행.
- 공통 비용은 배분 규칙·미배분액을 남기고 같은 비용을 여러 기능에 중복 합산하지 않음.
- 기간·대상·비용 기준·임계값별 첫 초과 알림을 기록해 중복 방지.
- Azure Budget 자체는 소비를 중단하지 않음. 임계값에서 선택 재분석부터 제한하고 필수 출결·일정 안내는 임의 중단하지 않음.
- 라이선스·환율·세금·계약·크레딧과 수동 보정은 근거·담당자를 기록.

## 운영 품질 기준

동일 범위·기간·통화의 포털 조회와 대조하고 스냅샷·사용 로그·수동 보정·배분의 중복을 검사합니다. 실시간 사용량과 지연된 비용을 구분하고 다른 구독·회사 리소스를 섞지 않습니다.
