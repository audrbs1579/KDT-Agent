# 운영 업무 리스트

[문서 목록](00_보고서_안내.md)

## 작성 목적과 기록 기준

에이전트를 만들기 전에 사람이 하던 교육 운영 작업을 설명하고, 업무별 상세 절차와 애매한 조건을 사용자가 기록하기 위한 통합 표입니다. 에이전트 구축·배포·권한 연결·모델 선정·비용 측정·구현 검증 작업은 이 목록에 포함하지 않습니다.

- 설계 문서에서 확인 가능한 운영 업무를 사람의 작업 이름으로 정리했습니다. 문서만으로 과거의 실제 수행 여부·담당자·세부 절차까지 확인했다고 보지는 않습니다.
- 예상 담당자는 문서에 명시된 사람의 역할만 기록했습니다. 기존 설계의 에이전트 담당을 임의의 사람 담당으로 바꾸지 않았습니다. 수강생 제출처럼 운영 과정에 참여하는 사람의 작업도 포함합니다.
- 빈칸은 해당 항목의 근거가 문서에 없다는 뜻입니다. 담당 불필요·자동화 확정이라는 뜻이 아닙니다. 업무를 설명하면서 각 칸을 직접 보완하면 됩니다.
- 업무와 의미는 사람이 하는 일로 적고, 자동화 관련 제약은 ‘자동화 시 주의할 점’에 적습니다. 현재 설계의 제약을 과거 운영 절차였다고 해석하지 않습니다.
- 초기 기획의 일별 강의 만족도는 현재 대화에서 정정한 ‘며칠에 걸친 한 강의 종료마다 객관식 2개·주관식 1개’ 기준으로 정리했습니다. 이미 제외한 태도 순위·수면 추정·자동 경고는 업무로 재등록하지 않았습니다.
- 업무명을 누르면 대응 설계의 근거 절로 이동합니다. 예시·조건은 설명용일 수 있으며 실제 담당자 배정이나 완료 실적이 아닙니다.

검토 기준: Git `828b919`와 이번 대화의 사용자 정정. 고용24 제출의 사용자 설명은 문서 끝에 함께 보존합니다.

## 고용24 제출 업무의 사용자 설명

## 사용자가 설명한 업무

KDT 과정에서 단위기간 출결 데이터와 출결 확인 서류 등을 고용24에 제출하는 업무입니다.

- 제출 대상: 고용24
- 제출 자료: 단위기간 출결 데이터, 출결 확인 서류 등
- 업무 성격: KDT에 특화된 전문 업무
- 자동화에 대한 사용자 설명: 에이전트가 수행하기 어려울 수 있음

### 대화 근거

> KDT과정의 경우 고용 24에게 단위기간 출결 데이터와 출결 확인 서류등을 제출하는 업무야 이거는 KDT 전문 업무이기도 하고 에이전트가 하기에 좀 어려울 수 있음

### 현재 확정하지 않은 내용

제출 방식·상세 절차·자동화 수준·사람과 에이전트의 담당 범위는 아직 확정하지 않았습니다. 이 기록은 사용자가 설명한 업무를 보존하기 위한 문서입니다. 에이전트의 역할을 ‘취합·검토 지원’으로 한정하거나, 업무를 ‘추후 개발 후보’로 분류하거나, 사람이 최종 제출한다고 확정하지 않습니다.
