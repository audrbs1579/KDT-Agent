# KDT Teams 폴더 구조 및 기능별 자료 위치 예시

## 해석 기준

- 수강생 팀의 파일 공유는 `일반 (General)` 탭 안에서 합니다. 출결·교육문의·멘토링 요청 등의 게시판 채널은 소통용이며, 별도 파일 공유 위치로 가정하지 않습니다.
- SharePoint에서 확인한 `일반` 하위 폴더 이름과, 사용자가 제공한 세부 폴더·파일 목록을 함께 정리했습니다. 세부 구조 전체를 SharePoint에서 직접 열어 검증한 결과는 아닙니다.
- 날짜·시간·주차·이름·강사명·강의명·파일명 및 세부 폴더 구성은 예시이며 고정값이 아닙니다. 실제 구성은 테스트 및 운영을 하면서 바꿀 수도 있습니다.
- 아래 이름은 업무 흐름과 저장 위치를 설명하기 위한 참고 자료입니다. 모든 기수에 공통 적용되는 표준이나 자동화 연동·권한이 확인된 경로를 뜻하지 않습니다.
- 파일 내용은 확인하지 않았으며, 아래에는 제공된 폴더명과 파일명만 기록합니다.
- 트리의 `※` 행은 이름·날짜 규칙을 설명하는 주석이며 실제 폴더나 파일이 아닙니다.

## 세 자료 영역의 역할

아래 구분과 기능별 매핑을 설계 보고서·기능 명세·이미지의 공통 참고 기준으로 사용합니다. **구조 예시를 제공받은 것과 실제 자동화 연결을 확인한 것은 다릅니다.** 팀·채널 유형, 소속 팀, 테넌트·사이트·드라이브·폴더 ID 및 읽기·쓰기 권한은 연결 시 별도로 확인합니다.

| 자료 영역 | 기준 위치 예시 | 역할·경계 |
|---|---|---|
| 수강생 팀 | `일반 (General) / 공유 탭` | 수강생에게 공개할 OT·시간표·강의자료·프로젝트 가이드·산출물·녹화. 파일 공유는 이 탭 안에서만 수행 |
| 기수별 운영 채널 | `{기수} 채널 / 공유 탭` (예: `11기 채널`) | 교육 가이드·운영 매뉴얼·상담·설문 결과·내부 출석부·행사 운영 자료. 소속 팀은 미확정이며 수강생 팀으로 간주하지 않음 |
| 강사팀 | `{기수} 강사팀 / 공유 탭` | 강사용 양식·결과보고서·멘토링 일지·강사 산출물·중간평가문제·호명 출석부. 수강생 공개 영역과 분리 |

`출석 관리 팀`은 위 세 영역과 별도의 외부 기관 출석 업무 역할입니다. 이번에 제공된 구조에는 포함되지 않았으며, 승인된 외부 전달이 필요할 때만 대상·자료 버전을 지정합니다. 내부 출결의 기본 보관소로 사용하지 않습니다.

## 자동화 설계 시 유의점

- 파일 공유 기준 위치는 `일반 (General)` 탭입니다. 위 예시 밖의 채널이나 폴더를 수강생 팀의 파일 공유 위치로 가정하지 않습니다.
- 폴더명 규칙은 검색·분류·보관 자동화의 후보로만 참고합니다. 날짜 형식, 강의명·강사명 표기, 회차·주차명은 실제 자료에 맞춰 조정해야 합니다.
- 이름이 비슷한 자료가 `05. 강의자료`와 `기타 자료` 양쪽에 있을 수 있으므로, 이름만으로 중복·최신본·정본 여부를 단정하지 않습니다.
- `03. 계정` 및 수강생 산출물 등에는 계정정보나 개인·민감정보가 포함될 수 있습니다. 자동화 적용 전 실제 파일 내용, 접근 권한, 처리 목적과 보관 기준을 확인해야 합니다.
- 이 문서는 폴더 구조 예시이며, 파일 내용 검토·계정정보 확인·권한 확인 또는 실제 자동 연동 검증을 의미하지 않습니다.

## AI 11기 기수별 운영 자료 구조 예시

아래는 사용자가 제공한 **AI 11기 자료 구조 예시**입니다. 앞 절의 수강생 팀 `일반 (General)` 탭 구조와 구분해 참고합니다. `11기 채널 (공유 탭)`이라는 명칭과 실제 운영상 위치는 제공된 설명을 옮긴 것이며, 다른 기수에 동일하게 적용되는 표준 구조라는 뜻은 아닙니다.

- 폴더·파일명, 날짜·회차, 연도·기수, 사람 이름, 강의·행사 정보는 모두 예시이며 변경될 수 있습니다. 실제 구성은 테스트 및 운영을 하면서 바꿀 수도 있습니다.

### 운영·자동화 검토 시 주의

- `중간평가 및 설문`은 기존 저장 위치 이름입니다. 만족도 유형을 여러 개 운영한다는 뜻이 아니며, 전체 과정 종료 시 1회 3항목 Forms → Logic Apps 응답 수집 → DB 집계 → 결과 Excel·요약 저장으로 개발합니다. 다운로드 사본은 장애 복구·대조용입니다. 참가 신청·동의서 등 다른 목적 양식은 해당 기능 기준을 따르며 실제 ID·권한·UI/수집 연결 검증은 별도입니다.
- 상담일지·중도퇴소·출결 경고·계정·합격자 명단·출석부 등은 개인 또는 민감정보가 포함될 수 있는 자료 유형입니다. 구조 예시만으로 자동 수집·열람·분석을 결정하지 말고, 목적·최소 권한·보관·승인 절차를 별도 확인합니다.
- 매뉴얼과 양식은 기수·시점에 따라 개정되거나 중복본이 있을 수 있습니다. 파일명만으로 최신본·적용 규정·업무 기준을 판단하지 않습니다.
- 제공된 일부 항목은 이름이 생략되거나 말줄임표로 잘려 있습니다. 원래 파일명을 추정해 보완하지 않았습니다.
