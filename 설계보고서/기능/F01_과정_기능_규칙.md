# F01. 과정·기능·운영 규칙

[전체 목록](../00_보고서_안내.md)

난이도: 3 · 기본 기능

## 목적

새 과정이 들어올 때 코드를 복사하는 대신 이름·기간·기능·규칙을 설정해 운영합니다.

## 입력·설정 (체크박스 On/Off + 커스텀 연결·기능·규칙 추가)

새 과정(기수)을 만들거나 운영 중일 때, 대시보드 설정 화면에서 **① 외부 연결과 개별 기능을 체크박스(토글)로 켜고 끌 수(On/Off) 있을 뿐 아니라**, **② 목록에 없던 새로운 연결(새 사이트·새 채널·새 엑셀 양식)이나 커스텀 자동화 기능을 직접 추가하고 그것도 체크박스로 켜고 끌 수 있는 구조**입니다.

**일정 운영 기준(사용자 설명·캘린더 기준): 한 기수는 수업일마다 하루 강의 일정 1개를 운영하고, 같은 날짜에 여러 기수가 각각의 강의를 동시에 운영합니다.** 기수별 달력에는 해당 기수의 일별 강의 하나가 보이며, 전체 달력의 같은 날짜에 보이는 여러 강의는 서로 다른 기수의 일정입니다. 강사·과목은 날짜에 따라 바뀔 수 있고, 공동 멘토링의 복수 담당자도 하루 일정 하나에 연결합니다. 오전·오후 출결이나 분할 녹화는 같은 하루 강의의 내부 구간입니다.

### 1) 기본 정보
- 과정명, 기수, 과정 유형·기간 프리셋(`KDT 6개월 표준형` / `3개월 과정` / `1~2일 단기 특강` / `출결 없는 과정` / `직접 커스텀`), 기간, 담당자, 시간대.

### 2) 연결 설정 (체크박스 On/Off + `+ 새 연결 추가`)
각 기수가 실제로 쓰는 외부 환경만 켭니다. 기존 커넥터·절차가 지원하는 계정·채널·폴더·양식은 화면에서 등록합니다. 새로운 사이트·인증·파서·동작은 개발·검증 후 활성화하며 URL 등록만으로 자동화되지 않습니다.
- `[☑/☐]` **`@dataschool` Teams 연결** (**4개 업무 역할 예시**: ① `{과정명} {기수} 수강생 팀`[공지·출결·LMS 정정 요청·교육문의·멘토링 요청 등의 소통 채널 및 파일 공유용 `일반`], ② `출석 관리 팀`[외부 기관 출석 업무의 승인 자료 공유], ③ `강사팀`[`{기수} 강사팀`], ④ 기수별 운영 채널[`{기수} 채널`, 소속 팀·별도 보고 채널은 실제 연결 시 확인] — 세부 채널별 체크박스 On/Off 및 **`+ 커스텀 채널 매핑 추가`** 가능. 자료 구조 예시는 아래 매핑을 따르고 실제 ID·채널 유형·권한은 별도 확인)
- `[☑/☐]` **`@elixirr` Outlook 일정·메일 연결** (1개월 단위 수업 이벤트 기준 캘린더·발신 메일함 지정)
- `[☑/☐]` **LMS(HRD-Net 등) 연결** (오전·오후 입퇴실 및 서류 조회용 URL·계정 참조)
- `[☑/☐]` **별도 중간출결 사이트 & 별도 VM ‘출결 종합 사이트’ 연결** (중간출결 수집 및 3종 출결 파일 종합용)
- `[☑/☐]` **문서 저장소·공유 엑셀 동시 편집·Microsoft Forms 응답 수집** (사람은 공유 엑셀·워드를 공동 편집하고 에이전트는 저장 파일을 다운로드·파싱. 과정 종료 만족도는 승인된 Forms의 과정별 자동 준비·종료 안내·Logic Apps 응답 수집·집계. 양식별 연결·OAuth·문항 매핑을 등록. 기타 Forms는 각 기능 기준이며 다운로드 사본은 복구·대조용)
- **`[+ 커스텀 연결 추가]`**: 새로운 외부 웹사이트(대학 자체 포털, 신규 설문/평가 도구, 외부 기관 웹페이지 등), 새 SharePoint 폴더, 새 엑셀 양식 경로를 화면에서 등록하고 체크박스 항목으로 추가 가능(웹 사이트는 [F19](F19_컴퓨터유즈_경험메모리.md) 컴퓨터 사용·브라우저 자동화 실행기와 연결).

#### 자료 영역별 연결 매핑

KDT 폴더 구조를 참고해 **수강생 팀 `일반`·기수별 운영 채널·강사팀**의 입력·결과 위치를 나눠 등록합니다. 수강생 파일 공유는 `일반` 안에서만 하며 다른 게시판은 소통용입니다. 운영 채널 루트 시간표와 `일반 / 02. 시간표` 중 기준 원본·배포본을 지정하고, 강사팀 `출석부` 읽기와 운영 채널 `출석부 / 월 / 주차 / 일자` 보관을 구분합니다.

예시 이름·날짜·세부 구성은 테스트 및 운영을 하면서 바꿀 수도 있습니다. 기수별 운영 채널의 소속 팀·실제 ID·권한, 과정 종료 설문 집계 Excel·요약 및 복구/기타 Forms 결과 저장 예정 위치인 `중간평가 및 설문`, 제한 증빙·개인 자료·퀴즈 정답 위치는 연결 시 확인합니다. 새 기수 복제 시 파일 ID·수강생 자료·권한까지 복사하지 않습니다.

### 3) 기능 및 커스텀 업무 설정 (체크박스 On/Off + `+ 커스텀 기능/업무 추가`)
기수마다 필요한 기능만 체크박스로 켜서 돌리고, 운영 중 임시로 멈추고 싶을 때는 체크박스를 끄면 새 실행을 차단하고 대기 예약을 취소합니다. 진행 중 작업은 안전한 중단 지점에서 멈추며 이미 전달된 외부 작업은 되돌린 것으로 표시하지 않습니다.
- **표준 기능 체크박스 (`[☑/☐]` 개별 On/Off):**
  - `[☑/☐]` 1개월 단위 Teams 채널 수업 생성·Outlook 연결 및 사전 승인된 강사 접근 연동 ([F04](F04_Teams_강의_강사소통.md), [F05](F05_Outlook_일정.md))
  - `[☑/☐]` 수업 전날/당일 담당 강사 교안·출석부·중간평가 확인 ([F04](F04_Teams_강의_강사소통.md))
  - `[☑/☐]` OT 체크리스트·명찰·동의서 현황 집계 ([F03](F03_OT_체크리스트.md))
  - `[☑/☐]` 출결 게시판의 사전 지각·조퇴·외출 예정 연계 LMS 입퇴실 확인·맞춤 안내 ([F15](F15_LMS_입퇴실.md))
  - `[☑/☐]` 별도 사이트 중간 출결 및 3종 출결 파일(출석부·중간출결·Teams 기록) 종합 연동 ([F16](F16_중간출결.md))
  - `[☑/☐]` **수기 입력 출결 모드 (프린트된 종이 엑셀 출석부 사용 과정 — 자필 서명·수기 체크는 AI 자동 판독 대신 사람이 직접 확인·입력하고 에이전트는 마감 알림·파일 보관만 수행)**
  - *(출결 없음 모드는 [F14](F14_LMS_서류_반려안내.md) 증빙·[F15](F15_LMS_입퇴실.md) LMS·[F16](F16_중간출결.md) 중간출결/종합을 포함한 출결 업무·예약·알림을 모두 OFF로 강제하고, 수기 입력 모드와 온라인 연동 모드는 동시에 켜지지 않도록 검증함)*
  - `[☑/☐]` 당일 교안·오전 수업 녹화 기반 일일 퀴즈 초안 생성 ([F07](F07_퀴즈.md))
  - `[☑/☐]` 과정 종료 시 1회 객관식 2개·주관식 1개 Forms 만족도 자동화 ([F06](F06_만족도조사.md)). 일별·중간·별도 특강/멘토링 만족도 예약은 생성하지 않음
  - `[☑/☐]` 수업 질문·답변(Q&A) 자동 취합 ([F08](F08_질문답변.md))
  - `[☑/☐]` LMS 병가·공결 증빙 서류(캡처·촬영·스캔본) 화질 판독·조건 검사(`진료확인서+질병코드` 또는   `진료확인서+질병코드가 있는 다른 증빙(처방전 등)`의 조합 및 커스텀 규칙) 및 매니저 최종 판단 후 결과 공지 ([F14](F14_LMS_서류_반려안내.md))
  - `[☑/☐]` 수업 녹화·음성 생성 확인 및 요약 보조 ([F10](F10_영상_수업관찰.md))
- **`[+ 커스텀 기능·자동화 업무 추가]` (직접 만들어 체크박스로 관리):**
  - 기본 기능에 없는 **새로운 반복 업무나 기수별 특수 업무**를 매니저가 **화면 폼 또는 자연어 지시**로 직접 만들어 목록에 등록할 수 있습니다.
  - **커스텀 기능 구성 요소:** `기능 이름` + `실행 시점(Trigger: 매주 특정 요일·수업 시작 N분 전·특정 엑셀 업로드 시·특정 게시판 글 등록 시 등)` + `입력 데이터(엑셀 시트/채널/폴더)` + `수행 동작(Teams 메시지/카드 발송, 엑셀 취합·가공, AI 요약, 브라우저/PC 절차 실행)` + `발송 대상 채널/담당자` + `승인 필요 여부`.
  - 한 번 추가한 커스텀 기능은 **표준 기능과 똑같이 대시보드에 `[☑/☐]` 체크박스로 등록**되어 언제든 켰다 껐다 할 수 있고, 다른 기수를 만들 때 그대로 복제해 재사용할 수 있습니다.

### 4) 세부 규칙 및 규모 한도
- 출결 신고: 게시판/정정 요청 연결, 신고 유형·예정 시각·유효 구간·변경/취소, 승인 대기 시 안내 조정, 확인/재조회·유예·개인 안내 정책을 F15 기준으로 설정합니다. 신고는 자동 수집·대조하고 중요한 공식 인정·정정은 승인에 연결합니다.
- 규칙: 각 체크박스 기능별 발생 조건, 실행 시각, 대상, 예외(휴일·방학 자동 제외), 재안내 횟수, 종료일, 승인 수준.
- 규모: 학생 수·동시 발송·PC 작업 한도.

## 처리 구조

```text
과정 개설·캘린더(시간표) 등록 시 기본 자동화 템플릿 즉시 적용 (명령 입력 불필요)
(예외적 규칙 추가·변경 시에만 화면 선택 또는 자연어 지시 사용)
→ 기수별 하루 강의 일정 1개와 날짜별 강사·과목으로 실행 일정 계산
→ 같은 날짜 여러 기수의 일정·대상·발송·응답을 독립적으로 관리
→ 서버가 허용 기능·필수 연결·충돌·휴일 검사
→ 규칙 버전 저장 및 전체 회차 자동 예약 갱신
```

사람이 반복 명령하지 않아도 확인된 연결·일정·기능으로 운영 업무를 계산합니다. Teams 수업은 월별로 발행하고 과정 종료 만족도는 승인된 3항목 템플릿의 준비·링크·양식별 수집 연결·과정 종료 확인 후 기본 안내 1회·집계를 자동 실행합니다. 원본 편집·퀴즈 정답/검수/게시·수기 출결과 중요 승인 등은 각 기능의 사람 작업으로 예약·대기 표시합니다. AI는 예외 규칙 초안이나 일정 텍스트 파싱을 돕고, 유효성 검사는 일반 코드가 수행합니다. 잘못된 조건을 “대충 적절한 기본값”으로 실행하지 않습니다.

## 리소스·권한

Container Apps, Foundry Agent Service, PostgreSQL, Durable Functions/Task Scheduler, Service Bus. 과정 관리자만 규칙을 수정하고 학생·강사는 자신에게 허용된 응답만 제출합니다.

## 저장·출력

`courses`, `feature_bindings`, `rule_versions`, `calendar_bindings`, `work_runs`.

필수 규칙 필드: `feature_id`, `scope`, `trigger`, `timezone`, `conditions`, `action`, `connection_id`, `exceptions`, `reminders`, `approval_policy`, `effective_from`, `effective_until`, `version`.

대시보드는 활성·준비 미완료·중지·오류를 구분합니다. 체크박스가 켜져 있어도 인증 미완료라면 “실행 준비 안 됨”입니다.

## 예외·승인

- Teams 해제 시 설문까지 무조건 삭제하지 않고 다른 발송 채널 선택을 요구합니다.
- LMS 해제 시 LMS 기반 출결 예약을 중단합니다.
- 휴강·수업 이동은 실행 직전에도 확인합니다.
- 과정 복제는 규칙·양식만 복제합니다. 학생·비밀·기존 대화 ID는 복사하지 않습니다.
- 과정 폐지는 대기 작업 취소·실행 중 안전 중단·보관 정책 적용으로 처리합니다.
- 승인된 범위 밖의 새 외부 제공·대량 발송·새 권한은 재승인합니다.

## 운영 품질 기준

KDT를 복제해 Teams 없는 단기과정을 만들고 기존 기능을 설정만으로 조합할 수 있어야 합니다. 휴강·기능 해제 후 해당 작업이 실행되지 않아야 합니다. 동일 명령을 재전달해도 같은 규칙/예약을 중복 생성하지 않아야 합니다.
