# F06. 일별·중간·최종 만족도

[전체 목록](../00_보고서_안내.md)

난이도: 3

## 목적

일별 강의 품질과 과정 전체 운영 만족도를 모아 추이를 확인합니다. 설문 원본·양식 버전을 보존하고, 결과를 운영 개선 사건과 연결합니다.

## 입력·설정

과정·수업 회차·**당일 담당 강사(복수 강사 또는 모듈별 강사 자동 매핑)**, 문항·척도, 배포 시점, 응답 기한, 재안내 횟수, 기명/익명 방식, 최소 집계 인원, 결과 열람 역할.

기본 예: 매일 수업 종료 시 **그날 강의한 담당 강사(및 과목 회차)**에 대해 자동 발송되는 일별 만족도(교안 준비·강의력), 커리어 멘토링 날(`커리어멘토링2` 등)에는 멘토링 만족도([F12](F12_멘토링_사전자료.md))로 자동 전환, 과정 전체 운영 만족도는 기수당 약 3회 자동 예약됩니다.

**결과 위치 예시:** 기수별 운영 채널의 `중간평가 및 설문`은 사람이 Forms 응답을 Excel로 내려받아 저장할 예정인 위치입니다. 설문별 원본·다운로드 시각·버전과 별도 집계 결과를 구분합니다. 파일이 이미 있거나 자동 동기화된다고 가정하지 않으며 강사팀 `중간평가문제`와도 구분합니다. 폴더·파일명·문항·일정은 테스트 및 운영을 하면서 바꿀 수도 있고 실제 ID·열람 권한은 연결 시 확인합니다. 개인 응답·내부 집계는 수강생 `일반`에 자동 공개하지 않습니다.

## 처리 구조

```text
수업/과정 일정 → 설문 초안·대상 준비 → 매니저가 문항 검수·Forms 게시·링크 등록
→ Teams 메시지/카드로 Forms 응답 링크 안내 (카드는 안내용이며 답변은 Forms에서 입력)
  (게시 완료·응답 가능 여부 확인 전 발송 보류)
→ 매니저가 Forms 응답 화면의 Excel 다운로드/내보내기 버튼으로 파일 저장·전달
→ 에이전트가 해당 시점의 응답 Excel 수집·양식 버전/응답 ID 검사·중복 제거
→ 기한/미응답 조건에 따른 Teams 재안내
→ SQL 점수·응답률 집계
→ AI가 허용된 주관식 의견 요약
→ 대시보드 및 운영 사건 후보
```

모든 설문은 별도 외부 사이트를 새로 만들지 않고 **Teams 안내 → Forms 응답 → Excel 다운로드 → 에이전트 정리**로 운영합니다. Forms 생성·검수·게시·응답 Excel 다운로드는 사람 담당입니다. 다운로드 파일은 자동 갱신 파일이 아니므로 새 응답은 다시 내려받고 기준 시각을 표시합니다. 다운로드 버튼의 자동 조작은 실제 검증한 경우에만 F19로 추가합니다.

## 리소스·권한

Microsoft Forms/Excel(SharePoint), PostgreSQL, Teams, Durable Functions, Service Bus, Foundry. 설문 응답은 지정한 과정·설문 버전에만 연결해 집계합니다.

## 저장·출력

`form_versions`, `survey_instances`, `responses`, `response_items`, `survey_summaries`.

문항별 평균·분포·응답률·기수별 추이, 주관식 요약과 원문 근거, Excel 내보내기. 만족도 4종 표준 문항과 집계 엑셀 컬럼은 09 데이터 컬럼·엑셀 양식을 따릅니다.

## 예외·승인

- 기명 설문은 개인별 미응답 안내 가능.
- 익명 설문은 응답 내용과 신원을 결합하지 않음. 완전 익명이라면 개인별 미응답 추적을 기본 제공하지 않고 전체 재안내로 처리.
- 소수 응답은 재식별 위험을 고려해 집계 공개 범위를 제한.
- 문항·척도가 바뀌면 단순 평균을 같은 지표로 비교하지 않음.
- 낮은 점수 한 건으로 강사·학생의 문제를 확정하지 않음.
- 링크 재사용·중복·기한 초과를 명시적으로 안내.

## 운영 품질 기준

응답 건수·점수 집계가 원본과 일치하고, 양식 변경 전후 버전이 분리되어야 합니다. 익명 모드에서 개인 답변 추적이 불가능해야 합니다. 휴강·철회 대상 발송이 차단되어야 합니다.
