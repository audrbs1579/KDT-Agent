# F17. 과정 유형·기간별 출결 운영 기준

[전체 목록](../00_보고서_안내.md)

난이도: 2~3

**범위 안내:** 현재 문서는 과정 유형·기간별 출결 모드의 참고 설계입니다. 파일명의 “단위기간 서류메일”은 기존 참조를 유지하기 위한 이름이며 해당 이메일 기능을 구현 완료하거나 현재 개발 범위에 넣었다는 뜻이 아닙니다. 원문의 단위기간 제출 서류 이메일·기관별 제출 패키지는 U03 추후 후보로 구분하며 실제 테스트·운영 필요에 따라 범위·순서를 변경할 수 있습니다.

## 목적

**KDT 6개월 과정이 기본 기준**이지만 3개월·1~2일 단기·출결 없음·프린트 출석부 수기 입력을 구분해 필요한 기능만 실행합니다. 설정으로 조합 가능한 범위와 사람 확인·새 연결 개발이 필요한 범위를 나눕니다.

## 입력·설정

- 과정 기간: `KDT 6개월` / `3개월` / `1~2일` / `직접 지정`.
- 출결 모드 체크박스: `[☑/☐ 온라인 연동]` / `[☑/☐ 수기 입력 출결]` / `[☑/☐ 출결 없음]`. **서로 배타적인 모드**로 검증합니다.
- 기능별 체크박스: [F14](F14_LMS_서류_반려안내.md) 증빙·[F15](F15_LMS_입퇴실.md) LMS 입퇴실·[F16](F16_중간출결.md) 중간출결/3종 종합 등.
- 업무별 대상 과정·회차, 확인된 내부 기수 채널의 출석부 폴더, 민감 증빙 위치, 담당자.

**자료 위치 예시:** KDT 폴더 구조의 강사팀 `출석부`를 호명 원본 위치로, 운영 채널 `출석부 / 월 / 주차 / 일자`를 내부 원본·종합본의 보관 목적지로 구분합니다. 운영 채널 `운영관리 매뉴얼`의 단위기간 출결 처리 안내·각종양식은 적용 버전을 확인할 참고 자료이며 해당 파일의 존재가 U03 서류메일 구현을 뜻하지 않습니다. 수기 입력 완료본도 지정된 내부 위치에 보관합니다. 이름·날짜·구성은 테스트 및 운영을 하면서 바꿀 수도 있으며 실제 ID·권한·규정은 별도 확인합니다.

| 유형 | 동작 | 실현 범위·사람 역할 |
|---|---|---|
| KDT 6개월 | [F14](F14_LMS_서류_반려안내.md) 증빙 1차 판독·매니저 판단, [F15](F15_LMS_입퇴실.md) 누락 안내, [F16](F16_중간출결.md) 3종 종합 | 기존 사이트·양식·권한·화면 절차 확인과 구현 필요. 동작을 이미 검증 완료한 것은 아님 |
| 3개월·1~2일 | 기간·수업 회차·적용 기능 변경 | 등록된 기능·양식은 설정으로 재사용 가능. 새 기관 규정·사이트·파서는 별도 구현·확인 |
| 출결 없음 | [F14](F14_LMS_서류_반려안내.md)~[F16](F16_중간출결.md) 등 출결 업무·예약·알림을 모두 비활성화 | 일정·Q&A·일반 설문은 별도 선택 가능. 꺼진 출결 기능의 의존 작업도 실행 차단 |
| 프린트 출석부 수기 입력 | 매니저·강사가 종이 출석부를 직접 확인·입력 | 자필·겹친 서명·시각·대리 서명 여부는 AI가 정확히 확정하기 어려움. 에이전트는 확인/입력 업무 알림·기한 관리·완료 파일 보관 담당 |

## 처리 구조

`모드·기능 선택 → 상충 설정·의존성 검사 → 기간/회차별 실행 규칙 생성 → 온라인 업무 또는 사람 확인·입력 업무 배정 → 결과·담당자·근거 기록 → 지정 내부 위치 보관`

모드 변경 시 남은 예약을 취소·재계산하며 진행 중 작업은 중단 가능 지점에서 멈춥니다. 수기 모드에서는 LMS/중간출결 자동 독촉과 온라인 3종 종합을 끄고, 입력 전 자료를 공식 출결 완료로 표시하지 않습니다.

## 리소스·권한

[F01](F01_과정_기능_규칙.md) 기능·규칙, PostgreSQL, 예약·대기열, Teams/SharePoint. 이미 등록·검증된 기능을 조합하는 설계이며 모든 신규 과정을 코드 변경 없이 처리한다는 보장은 아닙니다.

## 저장·출력

과정 기간·출결 모드, `feature_bindings`, `rule_versions`, `tasks`, `attendance_observations`, `attendance_decisions`, `documents`.

사람 확인자·입력 시각·파일 버전·미완료 상태와 내부 저장 결과를 기록합니다. 외부 기관과 출석 업무가 필요한 경우에만 **기관·수신 채널·자료 버전 지정 및 매니저 승인 후** 출석 관리 팀에 별도 전달합니다.

## 예외·승인

- 상충 모드·필수 연결 누락: 활성화 차단·담당자 알림.
- 실제 내부 폴더·채널 구조 미확정: 매핑 확인 대기, 임의 저장 금지.
- 수기 판독 불명확·입력 누락: 사람이 원본 확인. 추정 출결 자동 확정 금지.
- 민감 증빙을 외부 출석부와 함께 자동 공유하지 않음.

## 운영 품질 기준

기간이 달라져도 선택한 기능만 해당 회차에 실행되고, 출결 없음에서는 출결 업무가 생성되지 않아야 합니다. 수기 모드의 사람 역할·미완료 상태와 내부/외부 전달 구분을 확인합니다.
