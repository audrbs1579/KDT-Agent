# F21. 통합 대시보드·업무 진척도

[전체 목록](../00_보고서_안내.md)

난이도: 3

## 목적

운영국과 매니저가 여러 과정의 상태와 AI가 수행한 일을 한 화면에서 확인합니다. 학생 현황뿐 아니라 **데이터가 최신인지, 자동화가 실제로 성공했는지**도 표시합니다.

## 입력·설정

로그인 역할, 담당 과정, 표시 기간, 지표·필터, 업무 완료 조건, 경보 우선순위, 갱신 주기.

## 처리 구조

`업무 DB·수집 상태·실행 이벤트 → 권한 범위 필터 → SQL 집계 → 화면 표시 → 근거·실행 상세 → 필요한 승인/재처리`

AI는 요약을 제공하지만 완료율·인원·응답률 계산은 검증 가능한 코드/SQL이 담당합니다.

## 화면

**일정 표시 기준:** 한 기수는 수업일마다 하루 강의 일정 1개를 운영하며 같은 날짜에 여러 기수가 동시에 운영됩니다. 통합 달력의 같은 날짜에 여러 카드가 보여도 각 카드는 다른 기수의 당일 강의입니다. 공동 멘토링의 여러 강사명은 하나의 일정에 표시합니다. 과정별 종료 만족도의 미도래/준비/종료 확인/안내/수집/집계 상태를 표시하고 필터·권한·집계도 기수별로 구분합니다.

**출결 확인 화면:** 기수·학생·수업일별로 `게시판 사전 예정 → 실제 LMS/호명 기록 → 일치·예정 초과·확인 대기 → 다음 조치`를 표시합니다. 신고가 있어 일반 미클릭 안내를 보류한 이유와 다음 확인 시각을 보여주고, 신고 접수·공식 인정·LMS 정정 완료는 별도 배지로 표시합니다. 개인 사유는 제한된 담당자 화면에서만 열람합니다(F15·F16).

### 자료 위치 표시

KDT 폴더 구조에 맞춰 카드·파일 링크에 **수강생 `일반` / 기수별 운영 채널 / 강사팀**의 자료 영역과 자료 종류를 표시합니다. 강사팀 호명 출석부 수집, 운영 채널 `출석부 / 월 / 주차 / 일자`의 원본·종합본 보관, 수강생 `일반 / Recordings`의 녹화 상태를 별도로 집계합니다.

운영 채널 `중간평가 및 설문`은 저장 예정 예시와 과정 종료 설문의 실제 자동 수집·집계·결과 파일 생성 상태와 복구/기타 설문 다운로드 상태를 구분하고, 시간표는 기준 원본과 배포본을 표시합니다. **[사용자 제공 구조](../KDT_폴더_구조.md) 예시 / 실제 ID·권한 확인 / 연동 검증 완료**를 분리해 미확인 연결이 정상 작동 중으로 보이지 않게 합니다. 날짜·이름·파일명·세부 구성은 테스트 및 운영을 하면서 바꿀 수도 있습니다. 상담·계정·평가문제·퀴즈 정답의 링크·미리보기도 열람 역할로 제한합니다.

과정 종료 만족도는 **과정 종료 시 1회 객관식 2개·주관식 1개**를 받습니다. 과정별 Q1/Q2 결과에는 과정 기간·종료일·응답 수·문항 버전을 병기하고 5점 분포·주관식 주제/근거를 제공합니다. 같은 문항·척도의 종료 기수를 비교할 때만 비교 기준을 표시합니다. 일별 강의 추이나 개별 강사 점수로 분해하지 않습니다. 익명 모드에는 개인 미응답 명단을 만들지 않고, 연결 실패를 응답 0건으로 표시하지 않습니다. 수집/폼 준비 예외만 담당자에게 전달합니다([F06](F06_만족도조사.md)).

## 리소스·권한

Container Apps 웹 UI/API, PostgreSQL, Entra 인증, Teams 탭, Azure Monitor. 직원 기본 로그인은 `@elixirr`. 교육 계정은 직원 역할 매핑 없이 운영 화면 접근 불가.

## 저장·출력

화면 설정·필터, 업무 상태, 승인·재처리 요청과 감사 기록. 각 카드에 원천·기준 시각·규칙 버전·관련 파일/메시지·실행 ID를 연결합니다.

모든 정형 목록은 권한 범위 안에서 Excel 내보내기를 제공합니다.

## 예외·승인

- 데이터 수집 실패를 “문제 없음”으로 표시하지 않음.
- 알림 발송 성공을 실제 업무 완료로 간주하지 않음.
- 재처리 버튼은 새 실행 권한·현재 일정·승인을 재검사.
- 민감한 면접/병가/상담 정보는 요약 화면에서도 접근 제한.
- 여러 과정 선택 시 분모·기간·척도가 다른 지표를 무조건 합산하지 않음.
- 직원에게는 업무 수행 결과를, 학생에게는 필요한 본인 정보만 표시.

## 운영 품질 기준

대시보드 수치가 DB·원천과 일치하고, 연결 장애/오래된 데이터가 명확히 표시되어야 합니다. 담당 과정 변경·권한 회수 시 기존 화면/검색에서도 접근이 차단되어야 합니다.
