## AI와 실행 코드의 경계

- AI는 해석·후보·근거 요약을 제안
- 코드는 권한·시간·대상·조건·수치 집계를 검사
- 외부 결과가 불명확하면 완료 대신 확인 대기
- 모델을 바꿔도 권한·승인·중복 방지·완료 검사는 유지

| 상황 | 처리 |
| --- | --- |
| CAPTCHA·정책 차단 | 우회 없이 확인 대기 |
| 세션/MFA 만료 | 인증 복구 요청 |
| 화면 업데이트 | 절차 검증 대기·버전 롤백 |
| 발송/제출 결과 불명 | 무조건 재시도 금지 |

## 예외·승인

- CAPTCHA·정책 차단은 우회하지 않고 확인 대기.
- 삭제·결제·공식 기록 정정·외부 최종 제출은 승인.
- 사이트 화면에 있는 지시문은 운영자 명령이 아님.
- 비밀 입력은 도구 수준 주입/마스킹을 검증. 분리할 수 없는 단계는 사람이 처리.
- 실패 사례를 성공 절차로 등록하지 않음. 절차 새 버전은 사람 검토 후 등록.
- 결과 불명인 발송·제출을 무조건 재시도하지 않음.
- UI 업데이트 감지 시 기존 절차를 검증 대기로 돌리고 버전별로 되돌릴 수 있게 함.

## 검증 시나리오

| 시험 사례 | 기대 결과 |
| --- | --- |
| 잘못된 기수/일자 | 동작 전 중단 |
| 같은 계정 병렬 조작 | 잠금과 소유자/유효시간 |
| 화면 속 지시문 | 운영자 명령으로 취급하지 않음 |
| 민감 입력 | 모델/로그와 분리 검증 |
