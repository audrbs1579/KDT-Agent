## F 기능과 U 후보의 경계

- 현재 명세 F01~F19와 F21의 구현 경로를 먼저 구분
- U01~U05는 지금 구현 완료한 기능이 아닌 추후 후보
- 우선순위·도입 일정은 실제 테스트/운영 필요로 결정
- 강의별 표준 3항목 만족도는 F06 현재 범위

- 평가는 실제 발송을 차단한 도구에서 수행

## Teams 중심 전환과 기존 소통

- 기본 방향은 Teams 중심 운영
- 기존 필요한 단체방은 갑자기 중단하지 않음
- 카카오톡 일반 단체방 자동화는 유지 부담·정책·절차 검증이 필요한 후보
- 도입 시 기수·방·계정·수신 대상·전송 결과 확인

<!--
원문: ../설계보고서/12_추후_확장.md#future-updates

- **U01:** 규칙·절차 원본은 DB, 자동 개선 평가는 실제 발송이 차단된 도구로 수행하고 사람 검토 후 적용.
- **U02:** 기수별 채널 전환 상황을 확인하고, 도입할 때 방·계정·수신 대상·전송 결과를 검증. Teams 사용을 이유로 기존 기수의 필요한 소통을 갑자기 중단하지 않음.
- **U03:** F14 증빙·F16 출결의 원천과 확정 기록을 사용하되 제출 단위기간을 별도 관리합니다. 고용24 제출용 취합본·누락/상충 목록 준비와 전문 담당자의 확정/실제 제출을 분리하고, 제출 결과가 확인되기 전 완료로 처리하지 않습니다. 실제 양식·제출 채널·담당자·보완 절차 확인 후 구현 범위를 정합니다.
- **U05 범위:** 승인된 강의 3항목 템플릿 자동화까지 추후로 미루지 않습니다. F06의 양식별 연결·UI/인증 검증을 통과해 적용하고, 다른 설문·퀴즈는 해당 기능 기준을 유지합니다.
- **U04·U05:** 기존 결과와 대조하고 오류·부분 완료·재시도를 확인한 뒤 도입. 사람 확인이 필요한 단계까지 무조건 자동화한다고 약속하지 않음.

-->
